地图布局与探索流程

地图地标表示位置；探索站点表示玩家的一次停留。地图选区的关联地标必须与区域探索地点一致；南门只用于教学。

地图上改什么

本编辑器调整地标落点、地图选区、路径拐点与亮区边界，与 Godot 路线编辑仍为独立入口；当前已完成一次数据对齐及一致性校验，未实现统一编辑。路径拐点只负责画线，关联地标的排列不决定游玩顺序。坐标、区域和地标文字由地图文件读取；改变关联地标后须同步在 Godot 配置该区域的探索站点，每个区域只能映射一个选区。

在 Godot 配置流程

  1. 在文件系统打开 res://resources/campaign/regions/，双击图书馆 library.tres、主楼线 region_b.tres 或体育场线 region_c.tres。
  2. 在检查器展开 Stages。数组顺序就是站次；展开某站的 Choices，每项是该站的一个可选探索站点。
  3. 站点的 Place 引用已有地点资源；Encounter 引用已有敌阵；Power 控制强度。站点标识保持唯一。具体事件正文与抽取规则不在地图工具中编辑。
  4. 需要岔路，在同一站增加 Choices；下一站自动汇合。移动 Stages 项可调整先后；新增项需先创建对应资源，避免留下空项。
  5. 点击检查器顶部“校验”刷新概览与错误，再点“流程预览”查看当前修改。保存资源，停止并重启游戏，新探索读取已保存配置。校验会拒绝遗漏／跨区地标与正式路线中的南门。也可以打开 res://scenes/content/campus_flow_preview.tscn，选择区域并刷新已保存配置。

不兼容或迁移旧格式探索检查点，也不自动覆盖或删除存档。当前格式探索保存开局流程，配置更新从新探索生效；预览不读写玩家存档。第一版采用按站次推进、分叉后汇合，不支持任意跨站跳转。

详细字段、添加站点及使用边界见项目文档 docs/campaign/flow-authoring.md。
