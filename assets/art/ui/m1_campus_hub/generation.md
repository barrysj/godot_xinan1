# asset_012 生产记录

- 类型：校园修复站功能图标候选包，10 枚透明 SVG。
- 生产方式：Codex 手工矢量绘制；未调用生成式图片模型，未使用外部素材。
- 视觉依据：`data/visual/colors.json` 的日常层与异常层强调色；沿用探索 UI 的深色内芯、明亮主轮廓和少量青／品红状态色。
- 规格：每枚 `64×64`、透明背景、无可见文字、圆角端点与圆角连接；主要线宽 `3.5px`。
- 修订依据：根据 `asset_011` 质量检查意见移除所有烘焙品红状态点，并统一黄色语义。
- 色彩：主轮廓 `#F6F8FA`，功能线 `#22E0F0`，成长／资源收益强调 `#F7E733`；基础图标不使用品红。
- 目标用法：现有深色面板中的首页入口、侧栏入口、资源／消息状态；卡片背景、悬停、禁用、选中、品红未读状态点和角标数字由 Godot 原生控件绘制。
- 不包含：面板、按钮背景、文字、数值、头像、进度条、场景装饰、真实校园背景。
- 评审尺寸：64px 为设计基准，附带 32px／24px 缩放评审板；低于 24px 应切换更简化的 Godot 小图标或提高显示尺寸。
- 状态：资产已批准并接入 Godot；接入效果待人工评审。

## 正式提升与运行时派生

- `asset_012` 获负责人批准后，10 枚 SVG 提升为正式源资产。
- `runtime/` 下同名 PNG 使用本机 Chrome headless 从对应 SVG 确定性渲染，规格为 `64×64`、透明 RGBA；Godot 运行时加载 PNG，避免依赖编辑器临时 SVG 导入缓存。
- PNG 只承担引擎纹理格式转换，不改变构图、颜色或状态语义；SVG 继续作为正式可编辑源。
- Godot 运行时优先读取已导入纹理；首次检出尚无 `.import` 缓存时，改由 PNG 字节解码创建 `ImageTexture`，避免脚本解析阶段 `preload` 失败。导出仍使用正式导入资源。
