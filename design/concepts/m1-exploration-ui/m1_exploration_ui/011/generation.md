# 011 M1 探索 UI 正式资产与运行预览

011 是用户实际查看并批准的六图 UI 资产组合与独立 Godot 运行预览，不是正式玩法接入。正式提升只改变文件归档和 Manifest 状态，没有产生视觉变化，因此不另增视觉版本号。

- 011 初次评审时，校园记忆来自 010，人物事件／借阅终端／敌对守卫来自 009，浮窗／按钮来自 006；当前目录保存六张获批图片的原样副本。

- 交互与浮窗：继承 005／008 已验证的原生 UI；热点绘制改为 118×118 透明命中区内的 106×106 自由轮廓，不加统一方形底座。
