# 012 M1 探索 UI 浮窗与按钮候选

012 是针对 011 游戏内接入效果的局部视觉修订，只重做 `panel.png` 与 `button.png`。校园记忆、人物事件、借阅终端和敌对守卫四枚图标继续使用已批准 011，不产生重复版本。

用户反馈当前浮窗与按钮融入度一般，尤其按钮的风格、形状与配色不协调。评审确认按钮外侧规则白框主要来自 Godot `focus` StyleBox，不是 PNG；旧按钮自身另有亮色内描边。012 预览删除外层白框，让焦点沿按钮自身切角轮廓增亮。

## 生产与处理

- 工具：内置 imagegen，分别以 011 正式 `panel.png`、`button.png` 为编辑目标。
- 浮窗：蓝黑半透明信息片、单处切角、细青边与少量品红干扰刻度；降低双框、机械厚度和辉光。
- 按钮：深蓝黑低能量 Normal 底、单切角与小型异常刻度；移除整块亮青、胶囊轮廓、白色焦点框和通用手游 CTA 质感。
- 文字、图标、焦点和状态不烘焙进图片，由 Godot 原生控件承担。
- 原始透明输出裁去透明空边后保存为 `panel-source.png`（1544×686）与 `button-source.png`（2014×351）；使用 Lanczos3 规范化为运行候选 `panel.png`（518×230）与 `button.png`（287×50）。
- 两张候选均为 RGBA，Alpha 范围 0–255；技术报告未发现格式、尺寸或透明度问题。

## 运行预览

入口：`preview.tscn -- --ui-capture`。预览复用 011 已验证交互及四枚正式图标，背景切换为最新正式图书馆异变中庭；浮窗与按钮使用 NinePatch 边距，三尺寸输出到 `review/codex-workflow/preview-012/`。

Godot 4.7.2 Compatibility 实际运行输出 `EXPLORATION_UI_CANDIDATE PASS three sizes; details, cancel, focus, read, reward gate`。已查看 1920×1080 默认／详情与 1920×1200 详情截图：按钮在约 116×48 显示尺寸仍保留切角与品红刻度，焦点没有规则白色外框；浮窗未越界，NinePatch 没有拉坏角部，背景在深色面板内仍可辨认。

负责人于 2026-09-18 明确回复“这版可以。提升为正式资产。”，因此 012 已升级为 `selected / approved`。正式套件由 012 的浮窗与按钮、011 已批准的四枚热点图标组成；正式路径仍为 `assets/art/ui/m1_exploration_ui/`，没有复制或重生成图标。真实战役采用 NinePatch 保持切角，并删除旧的规则白色焦点框，以同轮廓增亮表示悬停／焦点。

热点名称条仍是程序文字，不属于本次两张获批图片。负责人建议用倾斜、不规则的深色条带提示可交互，并把具体名称移入点击弹窗；该方向已记录为后续视觉设计项，本次正式提升不提前生成或接入未评审的新条带。

## 最终提示词摘要

浮窗：以 011 为编辑目标，改成宽幅紧凑的蓝黑半透明异常信息片；单处右上切角、左侧短青色信号轨、少量品红干扰刻度、细边与克制辉光；透明外部，无文字、图标、关闭按钮或焦点框，避免厚双框与通用飞船 HUD。

按钮：以 011 为编辑目标，改成长而低的深蓝黑 Normal 母版；右上切角、左下小缺口、细青边与单个品红刻度；透明外部，无文字、图标、焦点框，避免亮青整块填充、胶囊形、厚描边与手游 CTA 质感。
