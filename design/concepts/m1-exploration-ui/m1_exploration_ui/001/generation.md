# M1 探索 UI 概念 001 · 制作记录

- 阶段：概念；状态：`unselected` + `pending`，未接入。
- 成品：`library-exploration-layout.svg`，1600 × 900 的手工矢量布局样板。
- SHA-256：`1437759b8ffcdd76a73a03107e4d34abac2c35183d7ebe0024aadcdf5f2ff9b1`。
- 制作方式：原生 SVG 组件研究；未选用或保存任何 AI 生成的虚构图书馆场景。
- 目的：供人工确认地点探索页的信息层级，而非交付可直接使用的整屏贴图。

## 方案

- 保留现有四站路线提示、四个地点热点与“只展开一个详情”的交互语义。
- 热点固定为校园记忆、人物事件、借阅终端、守卫战；借阅终端为当前选中项。
- 详情区只提供短操作“查看”。将来实现使用 Godot 原生 `Container`、Theme 和矢量图标；不把按钮、正文或边框烘焙进背景。
- 左侧场景框是明确的“场景资料待补”占位，未生成或宣称图书馆建筑、校史、地理或人物。

## 资料缺口与下一关

正式环境概念前仍需要：至少一张允许使用的图书馆原照、来源／使用范围，以及地点身份与必要短回忆。拿到资料后，先另做受该资料约束的场景概念版本，仍须人工批准概念后才制作资产。
