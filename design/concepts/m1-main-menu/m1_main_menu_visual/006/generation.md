# M1 主菜单异常场景概念 · concept_006

## 目的

为三张校园地点概念图制作对应的异常状态版本，用于主菜单 review 试接入。异常版必须先保留地点身份，再通过记忆失真、数据化反射、几何错位和青／品红光效让玩家察觉“校园不正常”。完整终局通关后，菜单切换回正常主题图。

## 生成方向

- 图书馆：保留湖畔白色建筑与宽阔湖面；异常集中在建筑倒影，使用断裂的记忆镜面、重复窗带、青／品红反射、少量漂浮几何碎片；左侧天空和湖面保持低信息，作为菜单安全区。
- 品学楼：保留正面中轴、喷泉、广场和两侧树线；喷泉变成分段悬浮水弧与数据水滴，地砖线变为汇向入口的电路线，窗面和路径灯出现少量错误脉冲；建筑仍保持对称可读。
- 秋天银杏主楼：保留金色银杏大道和主楼正立面；主楼正中大门列必须与道路双黄线中轴对齐，保留去旗帜、去旗杆、去左侧岔路结果；异常集中在几何化落叶、重复枝形、青色道路脉冲、品红路径灯和少量立面错位反射。

## 人工质量闸门

结果为 `PASS_WITH_NOTES`：三张均能在几秒内识别对应地点；异常强度有明显区分但没有遮蔽地标；没有出现怪物、人物、可读伪文字或水印；银杏版继续满足大门—道路中轴约束。当前仍为概念候选，异常视觉与主菜单安全区等待负责人确认。
