# 项目美术生产

从美术主入口 `docs/art/WORKFLOW.md` 开始，再按任务读取 `docs/art/ART_CONTRACT.md` 及必要规范；不在此维护另一套生产与评审流程。

## 按任务读取

- **设计／生成：**相关领域 Spec、必要的 STYLE_BIBLE 章节、对应 Token、身份参考。可在用户范围内提出概念，不强制转交网页版；首次建立新视觉类别或明确改变总方向时才需要通读视觉圣经。
- **处理／接入：**当前任务与批准版本、Manifest、对应元数据及必要 Token；查尺寸、裁切和锚点优先用已有元数据，接入前验证其准确性。
- **QA／修复：**实际截图、明确意见和涉及的组件、资源与规范；只在有疑问时进一步看相关原图，不反复扫描全部图片。
- **流程整理：**读取直接涉及的规则文件和引用；不因文档整理生成资产或更改审批状态。

## 操作要点

- 位图生成／编辑使用 imagegen 技能与当前可用工具，正式项目文件须复制入仓库；已有矢量、简单 UI 和原生组件继续用原有实现。
- 每个阶段以具体版本供负责人评审，生成成功、技术检查通过和本地提交均不能替代人工决定；意见允许自然语言，由 Codex 整理为具体修改。
- 复用 Theme、共享组件、Token、切帧工具与预览场景。不要为了统一视觉参数重构任务外页面。
- 一次围绕一个功能或资产任务推进；提示词引用规范，不复述规范。任务或 Manifest 已能回答的信息不重复索取。
- 完成后简要报告修改、验证、评审状态与遗留问题；实际运行截图按项目规则展示。
