# Debug 战斗修改器

双击 `CampusDebugLauncher.exe`，点击“战斗试玩”：沿用原序章遭遇和四人阵容，停在整备。等待和修改都不会启动战斗，准备好后点击原“开战”。完整校园 Debug 的战前／未结算战斗也使用相同工具。

## 战场直接操作

- **拖动敌人**：在原有六个敌方阵位间移动；空位直接落位，已有敌人时交换。拖动时显示半透明角色、有效阵位和目标高亮；拖到场外、右键或 Esc 取消。敌人保持原数值，不累乘强度。
- **拖动同学**：场上拖动复用原编队同步和六个我方阵位，移动／交换后继续整备；原手牌部署操作保留。
- **单击双方角色**：在角色附近弹出快捷菜单，更换现有角色并调整生命、攻击、防御、攻击间隔、射程、移速。输入是草稿，“应用修改”后满血返回整备，等待再次点击“开战”。快捷编辑和拖动只在整备阶段开放；开战后双方点击回到原只读详情，手动暂停也不解锁编辑。取消、点外部或 Esc 丢弃草稿并恢复此前暂停状态。Tab 焦点在菜单内循环，F8 可切到完整调试面板。

友方选择现有7名已注册角色，已经部署的其他同学禁选，不永久解锁。换人使用所选同学原技能、动画、装备与成长基准；单独编辑的六项值是最终绝对属性，优先于下面的己方倍率。替换绑定原编队角色的临时标识，拖动后随同学移动；原编队、解锁和存档中的人物身份不被临时替换。原手牌头像与预览同步显示替换结果，避免战场和手牌显示不同角色。

敌方表现统一朝左，包括首次整备、序列帧、混合动画、移动／攻击／死亡和拖动预览。只约束显示朝向，寻路、目标、技能与弹道继续使用原模拟方向；原运行契约见[战斗动画](../combat/animation.md)。

## 完整场景配置

F8／右上角“调试” → “战斗修改”：

- 六个敌方图标位置，从现有10种敌人中选择、设为空位或重复放置；至少保留一名。
- 跟随地点，或选择已有庭院日间／实验室夜间／教室异常背景，即时预览。
- 单个敌人的六项最终属性，己方生命／攻击倍率。

整备中按钮为“应用修改”，应用后继续整备；已经开战时或完整校园调试的战报中，按钮为“应用重开”，走原重开／开战入口。快捷角色菜单仅在整备时开放。“恢复默认”只改草稿，须应用后才恢复普通角色、敌阵、背景和数值，当前原编队阵位保留。自定义属性启用时普通难度选择禁用，恢复默认后重新开放。

## 试玩结束

战斗试玩的胜利和失败都留在原战报，保留耗时、伤害与治疗统计，仅显示“退出游戏”和“重新战斗”。不会领奖、回地图或推进校园解锁。结果页关闭调试／暂停菜单入口，旧领奖和菜单点击区域也不可穿透。

“重新战斗”走原重开和保存接口，保留本次敌阵、背景、角色替换、最终属性与原阵位，恢复全员状态、清空统计后返回整备，不直接开战；保存失败保留原配置与结果页，显示错误并可重试。“退出游戏”沿用原退出原语关闭本次试玩，不增加临时预览档的保存确认。原调试跳过也进入该战报。完整校园Debug／Release继续原奖励与地图流程。

## 数据与应用边界

这些设置只存在于当前 Debug 进程，绑定活动局、地点、站次／终局阶段和遭遇；进入另一场清除，关闭游戏不保留。敌人 Resource、背景素材、原构筑、两种玩家档与存档 schema 沿用现有定义，Release 拒绝修改器。

整备编辑只重建原单位实例，不写检查点；开战后编辑先通过原重开入口保存检查点，再按所选操作重建或开战。保存失败保留旧配置和可继续编辑的菜单，原 Campaign 解码省略临时战斗节点时补回同一遭遇上下文。敌阵和友方身份在原单位初始化前确定，技能、代码效果与动画仍来自原系统；属性在原成长／装备／强度之后作用于实例。

## 实现与验证

- `game/debug/battle_tuning.gd`：注册内容、输入校验、草稿快照、战斗作用域、角色替换与应用／回退。
- `scenes/expedition/battle_context_editor.gd`：单一点击／拖动手势、阵位预览、附近快捷菜单、焦点与暂停恢复。
- `battle_preview_results.gd`：试玩结果的两个按钮、焦点、窗口适配和错误提示，统计仍由原战报绘制。
- `battle_tuning_panel.gd`、`debug_panel.gd`：共享 Theme／颜色、完整敌阵和背景配置。
- `campaign_hub.gd`：Debug 整备启动、临时角色与背景接口；`deployment_panel.gd` 继续维护原编队。
- `scenes/battle_demo/unit_presentation.gd`、`pixel_battle.gd`：初始与持续朝向、共用帧／混合呈现。

内部回归命令：

```powershell
pwsh.exe -NoProfile -File tools/development/tests/battle-tuning.test.ps1 -EnginePath '<Godot console.exe>'
pwsh.exe -NoProfile -File tools/development/tests/battle-tuning.test.ps1 -Capture -EnginePath '<Godot GUI.exe>'
```

同一入口运行完整修改器、直接整备和试玩结果三组真实 Campaign 回归，包含 Debug／关闭模式、鼠标拖动交换／非法落点／取消、整备单击双方菜单、战中只读点击／禁止拖动、实际键盘输入／应用、三尺寸、技能／身份／数值和背景生效、原模拟推进、重复友方拒绝、暂停恢复、保存失败重试、临时设置不入档与自然胜败／结果两按钮、配置保留重试／失败回退、真实退出、原 Resource／两玩家档不变。结果、基线与平台边界见 [DEV-01](dev-01.md)。

本轮不提供自由放置到网格外、永久资源编辑、预设导入导出、敌人技能创造或跨平台验收。
