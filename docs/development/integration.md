# 跨领域集成约束

2026-10-10核对基线d99750b；这里维护当前共享边界，功能细节就地写入各领域。删除历史歧义处理表和每次合并过程，Git负责追溯。

- 原玩家入口复用meta_hub→expedition→pixel_battle→battle_demo，战役控制器和显示仍较集中。增量拆分围绕实际痛点，不建设平行战斗或存档。
- 战役选路／地点与局外派遣地图职责不同，同名library不代表同一状态。地图JSON管空间，区域Resource管站次、分支和内容，热点JSON管多轮事件；不要从关联地标排列推断游玩顺序。
- 装备详情和队伍面板共用归属模型、属性口径与图标；修改任一入口需核对另一入口。新局成长版本2有有限装备／训练预算，旧构筑保持版本1。
- profile v4、CampaignCheckpoint外壳1、Journey2和ShortRun8分别管理不同层。Journey2只接受当前活动战役格式，旧探索需重开；永久profile迁移与旧构筑独立。新局冻结区域定义和奖励，人物／敌人Resource与地图地标不属于完整冻结快照。
- 永久教学、回忆、终端、人物兑现与结局收益必须幂等且保存成功后展示；普通局内先改内存再保存不等于交易回滚。失败、坏格式、对象归属、空池和JSON数值类型各按原编解码处理。
- 模拟层提供唯一动作时钟、事件和命中事实，帧／骨骼／AnimationPlayer只消费context；不以图片动画决定伤害。原子支付、个人产码与全队吸收规则共享，HUD不增加另一资源模型。
- 正式运行包不得引用版本化候选路径；源模型、参考、最终转绘和许可留在design，运行子集留assets。资源台普通浏览／预览只读，GIF生产显式触发，当前状态不从校验或目录推断。
- Web路径映射、实际变体、Manifest和导出排除必须一起核验；新图片组扩展生成与检查覆盖。桌面原图批准不自动表示缩图、手机或Web已验。
- 手动暂停、菜单、操作详情和Debug暂停分别恢复进入前状态；退出页面清理人物、意图与飘字。错误退出码、旧缓存和旧PASS不能覆盖当前完成标记或失败。

运行与存档详见[战役](../campaign/README.md)、[战斗](../combat/README.md)和[存档](../progression/README.md)；生产归[美术工作流](../art/WORKFLOW.md)，验证方式归[共用说明](verification.md)。真实设备、真人体验和最终资产状态保留未验边界。
