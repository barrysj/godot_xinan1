# 局外校园大地图

基地成长区的「大地图」打开现有派遣地点总览，目前包含旧图书馆和体育馆仓库。地图沿用占位建筑和庭院配色，未新增正式美术资产。

- 悬停建筑：高亮并弹出地点名；离开后收起。
- 点击建筑：弹出地点介绍、解锁条件、消耗、时长和收益。未解锁地点也可查看。
- 点击「关闭」或按 Esc：关闭详情，不打开暂停菜单。弹窗期间拦截底层地图和派遣按钮。
- 滚轮：以光标位置缩放，范围 1～2.5 倍；按住左键拖动浏览，拖动不会误触详情。
- 点击「复位」：恢复全图。地图获得键盘焦点后，左右键切换地点，Enter／空格查看详情。
- 关闭详情后，在右侧选择支援同学并「派遣」；原有扣费、计时、领取与存档规则保持不变。

地点仍由 `game/meta/meta_catalog.gd` 的 `LOCATIONS` 管理；`map_position` 是 1200×680 地图空间内的建筑中心点，新增地点无需修改点击坐标逻辑。地图组件 `campus_map.gd` 只负责浏览和发出选择信号，`meta_hub.gd` 负责详情及原有派遣交易。

## 验证

PowerShell 7 启动 Godot，参数：`--path . res://scenes/expedition/expedition.tscn -- --map-check`。使用独立测试数据，不读取或修改玩家档案；窗口模式输出 1920×1080、2560×1440、1920×1200 的悬停和详情截图到 `.godot/campus-map-*.png`。追加 `--headless`（置于 `--path` 前）可执行无窗口交互检查。原有派遣和存档回归使用 `--meta-smoke`。
