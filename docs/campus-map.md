# 局外校园大地图

基地成长区的「大地图」打开现有派遣地点总览，目前包含旧图书馆和体育馆仓库。地图沿用占位建筑和庭院配色，未新增正式美术资产。

- 悬停建筑：高亮并弹出地点名；离开后收起。
- 点击建筑：弹出地点介绍、解锁条件、消耗、时长和收益；右侧直接选择派遣队伍。未解锁地点也可查看。
- 点击「关闭」或按 Esc：关闭详情，不打开暂停菜单。弹窗期间拦截底层地图和派遣按钮。
- 滚轮：以光标位置缩放，范围 1～2.5 倍；按住左键拖动浏览，拖动不会误触详情。
- 点击「复位」：恢复全图。地图获得键盘焦点后，左右键切换地点，Enter／空格查看详情。
- 详情右侧列出全部支援同学：占位头像、姓名、彩色技能标签和选择按钮。未加入或执行任务中的成员头像置灰，并说明原因。
- 点击「选择」／「取消」多选成员，顶部实时显示 `n/m`；人数恰好满足地点要求、成员可用、技能条件满足且资源与队伍名额足够时才能「派遣」。
- 一队只扣一次地点费用、占一个队伍名额、发放一次收益；队内所有成员在领取成果后归队。地图右侧保留「查看详情」入口，不再提供单人派遣捷径。

地点仍由 `game/meta/meta_catalog.gd` 的 `LOCATIONS` 管理；`map_position` 是 1200×680 地图空间内的建筑中心点，新增地点无需修改点击坐标逻辑。地图组件 `campus_map.gd` 只负责浏览和发出选择信号，`meta_hub.gd` 负责详情及原有派遣交易。

## 派遣配置与存档

- `LOCATIONS.crew_size` 是事件要求人数：目前旧图书馆为 1、体育馆仓库为 2。
- `STAFF.tags` 引用 `DISPATCH_TAGS` 中的名称与底色。目前有考据家、美食家、运动健将、巧手；不附加隐含收益效果。
- `LOCATIONS.required_tags` 可配置队伍必须覆盖的标签，每项由至少一名成员拥有即可；目前两地点均不限标签。
- `location_dispatch_panel.gd` 管理详情与多选；`campus_progress.gd` 统一校验成员、人数、标签、名额和费用，保存失败整队回滚。
- 存档升级为 v3，任务以 `staff_ids` 保存整队。兼容 v1/v2 单人任务，旧体育馆任务不会因新人数要求失效，按原时长和收益领取。

## 验证

PowerShell 7 启动 Godot，参数：`--path . res://scenes/expedition/expedition.tscn -- --map-check`。使用独立测试数据，不读取或修改玩家档案；窗口模式输出 1920×1080、2560×1440、1920×1200 的悬停和详情截图到 `.godot/campus-map-*.png`。追加 `--headless`（置于 `--path` 前）可执行无窗口交互检查。原有派遣和存档回归使用 `--meta-smoke`。

多人派遣专项入口为 `--dispatch-check`，覆盖整队交易、成员校验、读档迁移、保存失败回滚、多选人数和灰色状态；窗口模式将实际截图写入 `.godot/dispatch-crew-*.png`。所有专项测试使用 `.godot` 内独立档案。
