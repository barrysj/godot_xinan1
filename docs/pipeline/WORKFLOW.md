# ChatGPT 网页版 × Codex 美术实现工作流

## 阶段 1：设计
在 ChatGPT 网页版完成需求、UX、美术方向、角色/场景/UI 概念、正式资产生成与视觉审核。此阶段不要调用 Codex 做开放式设计探索。

## 阶段 2：冻结
冻结：页面/场景目标、视觉稿、资产文件、交互规则、动效规则、响应式要求、验收条件。写入一个 Task Spec。

## 阶段 3：登记资产
每个最终资产：
1. 放入 `assets/art/`
2. 更新 `asset_manifest.yaml`
3. 状态改为 `approved`
4. 记录路径、尺寸、透明、Anchor、裁切、NinePatch、用途

## 阶段 4：交给 Codex
Prompt 尽量短，只写：做什么、读哪些文件、用哪些资产、禁止什么、如何验收。不要重复整份美术圣经。

## 阶段 5：Codex 实现
负责 Godot Scene、UI、Theme、Shader、动画、数据绑定、响应式、测试。不负责重新设计视觉、随意生成美术、修改已批准资产、自己决定品牌色。

## 阶段 6：视觉 QA
将运行截图交回 ChatGPT，只输出明确问题清单，例如：
- 女主立绘右侧被裁掉约 6%
- 课程格行高过密
- 主强调黄面积过大
- 关系节点连接线层级压住头像

禁止：“整体再好看一点”“更有感觉一些”。

## 阶段 7：收尾
确认：Task Spec 验收项完成、Manifest 更新、无临时资源、Token 未被重复硬编码、目标分辨率正常。
