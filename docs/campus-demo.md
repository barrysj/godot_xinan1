# 校园短局 Demo

启动：在项目目录执行 `pwsh.exe -File .\run-campus-demo.ps1`；或 Godot 按 F5 → Play。旧的 `run-battle-demo.ps1` 仍可进入独立战斗实验室。

## 已实现的完整流程

安全教室 → 选择出发补给 → 5 个路线节点 → 战前编队 → 自动战斗 → 贡献统计 → 三选一奖励 → Boss → 结算 → 永久解锁 → 再次出发。

- 路线有补给事件和精英战两条分支，共用起点与终点；每层只能选择一个地点。
- 战前点击角色、再点格子换位；选中守护者显示护盾覆盖范围。点击敌人可查看其技能，战中也可点角色查看状态。
- 胜利全员恢复；失败返回战前，保留本局阵容、装备和强化，无限重试。
- 篮球鞋缩短攻击间隔 25%；厚笔记本增加生命上限 80。同一名同学只能携带一件，换装后另一件退回背包。
- 三选一奖励包含装备、训练和新同学。训练永久保留到本次探索结束；招募发明家后，可选中上阵同学，再点击“换入发明家”完成候补轮换。离场同学携带的装备保留，可以再分配给其他人。
- 发明家每 3 次普攻对目标所在整排造成 72 点基础伤害。
- 结算展示实际扣除生命的伤害（不计过量伤害）与有效治疗。
- 通关带回修复资源：基础 7 点，每选一场精英额外 +1，最多 9 点。花 3 点解锁厚笔记本出发补给，后续每局可选择携带。

## 保存与暂停

局外资源、解锁、当前探索和派遣任务一起保存在 `user://campus_progress.json`（版本 2）；旧版资源与补给解锁会自动迁移。写入临时文件后替换正式存档；保存失败会提示，资源扣除和领取会回滚，无法识别的旧文件不会被覆盖。

选路、编队、换装、领奖和战斗结果均自动保存。点击“菜单”或 Esc / P 可暂停，选择“返回基地 · 成长与派遣”保存探索并管理基地；返回主菜单或退出时也会保存。下次进入安全教室后点击“继续探索”。中断的战斗从该场战前状态重开；已完成的战报和待选奖励会原样恢复，不会重复结算。未完成探索时开始新局需确认替换。新局清空局内强化与招募，保留局外解锁。

## 场外成长与派遣

基地的“功能与能力解锁”可消费通关带回的修复资源：

| 项目 | 消耗 | 效果 |
| --- | --- | --- |
| 出发补给 | 3 | 新探索可选携带厚笔记本 |
| 基础体能 | 4 / 6 / 8 | 每级全队生命 +20，最多三级，从下一次新探索生效 |
| 派遣事务所 | 3 | 开启派遣与旧图书馆 |
| 体育馆通行证 | 4 | 事务所解锁后，开放体育馆仓库 |
| 后勤扩编 | 6 | 事务所解锁后，增加一位支援同学，并行队伍增至两队 |

派遣使用独立支援人员，不占用战斗阵容。先选空闲同学，再选地点；出发立即扣除资源，到期手动领取后归队。旧图书馆消耗 2、耗时 60 秒、返回 4；体育馆消耗 4、耗时 120 秒、返回 7。当前时长便于 Demo 验证，后续可配置。使用本机现实时间，暂停和离线仍会推进；这是本地存档基础实现，没有云同步或服务器时钟。

扩展入口：`game/meta/meta_catalog.gd` 配置升级、人员、地点和收益；`campus_progress.gd` 管理交易与统一存档；`game/run/run_checkpoint.gd` 校验续玩状态；`scenes/expedition/meta_hub.gd` 连接基地界面和探索流程。新增能力效果需在构建新探索/单位时接入。

## 验证与边界

`pwsh.exe -File .\run-campus-demo.ps1 -Smoke` 用独立测试存档实跑安全路线、精英路线与招募阵容；检查奖励不可重复领取、胜利恢复、失败保留构筑、结算幂等、存档重读、永久解锁和暂停恢复。

`pwsh.exe -File .\run-campus-demo.ps1 -MetaSmoke` 检查旧存档迁移、续玩、战报/奖励恢复、能力生效时机、派遣离线结算、重复领取、人员占用和写入失败回滚。测试与截图使用 `.godot/` 下的独立档案，不写玩家存档。

当前使用五层固定连线结构，中间六个地点随机组合，奖励从七项定义中按条件抽取三项。尚未扩展地图层数、随机连线或更多地点内容。自动战斗在本地验证阵容下每场约 7～14 秒，实际整局时间取决于阅读与调整次数，尚未达到正式版时长与难度目标。没有实测手机或 Web 导出；仍使用临时像素人物与场景。

### 中文字体渲染

思源黑体在当前 Godot 4.7.2 Compatibility 渲染下开启 MSDF 时，“功”“所”等字出现多余黑块；同字对照中 nearest 与 linear 均复现，关闭 MSDF 后消失。因此字体导入关闭 `multichannel_signed_distance_field`，使用 2 倍 oversampling 保持缩放清晰。像素素材仍使用 nearest。修改字体导入设置后，应重新导入，并运行 `--meta-capture` 目视检查基地“功能与能力解锁”和成长页“派遣事务所”；仅启动成功不足以验证此问题。

## 校园图鉴

主菜单与暂停菜单均可打开“校园图鉴”。当前分人物、敌人、道具、地点、事件五类，共 31 个条目，全部开放查阅。人物/敌人沿用当前像素立绘；路线、派遣地点和技能说明复用现有目录数据。正文与条目列表可滚动。按返回或 Esc / P 关闭；从暂停进入时返回暂停菜单，继续游戏后才恢复战斗。

“出发补给”是永久解锁项，作用是在新探索开始时可携带厚笔记本装备（装备者生命上限 +80）。基地开关改称“出发装备”，具体获取方式与使用规则见图鉴的道具页。

图鉴数据入口：`game/codex/codex_catalog.gd`；通用覆盖页面：`scenes/codex/codex_panel.gd`。集成检查可通过 Godot 启动 `res://scenes/menu/menu.tscn -- --codex-check`，逐项浏览并检查从两个入口打开、关闭及战斗暂停恢复，截图写入 `.godot/codex_*.png`，使用独立测试存档。

## 随机路线与奖励

新探索固定从旧校门出发、到放学铃首领结束，中间三层每层两个随机地点，同局地点不重复。每层至少一个非精英选项，战斗强度按所处层数递增。随机的是地点顺序与组合，目前层数和相邻层全连通结构不变。

奖励从厚笔记本、发明家招募、五种角色训练中无放回抽取三项；已拥有装备/已招募角色不会再抽到对应获取奖励，只有已加入角色才会出现其训练。训练可重复获得并叠加。新加应援者与冲刺手训练，均为本局生命 +50、攻击 +5。

探索序列化升级到 schema 2，保存 31 位整数种子和已抽取的奖励 ID；地图按同版本种子重建，奖励直接恢复，浏览、重试或续玩不会重抽。schema 1 旧局继续使用原路线和奖励，下一次新探索才启用随机生成。将来改变生成算法应升级 schema 并保留旧版本恢复逻辑。

验证：启动 expedition.tscn 并传入 `-- --random-check`（需要图形渲染以输出截图）。覆盖 200 个种子的地图/奖励差异、合法性、JSON 往返、40 条路径实战和待选奖励磁盘恢复。旧 `-Smoke` / `-MetaSmoke` 保留固定场景，继续覆盖旧档兼容和基础规则。

## 地图点选
局内路线在校园地图上点选当前层地点，右侧查看详情并进入；局外派遣点击图书馆或体育馆建筑，右侧选人并确认出发。底部显示队伍倒计时与领取入口。锁定地点和忙碌人员仍由派遣服务校验，地图选择不会扣费。

## 队伍状态、装备与技能面板

路线地图和战斗界面顶部的“队伍面板”打开深色整备终端，分状态总览、装备配置、自动技能三页。显示当前生命/上限、攻击、防御、攻击间隔、本局训练、永久生命加成、装备与技能普攻计数。

地图和战前可换装、卸装、调整六格阵型、从候补换入角色；装备互斥和四人上阵约束保持一致，调整后保存。战斗中打开为暂停快照，只读，关闭后恢复原暂停状态。技能仍是每位角色固定的自动技能，没有技能池，当前通过角色、阵型和装备调整战术。

`-- --team-check` 可验证实际面板入口、换装互斥、卸装、候补替换、阵容存档、战中禁止修改和 Esc 恢复，并生成 `.godot/team_status.png`、`team_equipment.png`、`team_skills.png`。需要图形渲染；测试使用独立存档。

装备页使用图标槽位，点击弹出说明及背包备选，点选备选即换装；弹窗内可卸装，战斗中保持只读。

人物以头像选择，阵容采用前后两排六格。点击格子打开同学详情与头像备选，选择后交换站位或换入候补；空格只允许移动已有上阵同学，保持四人上阵。
