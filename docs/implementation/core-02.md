## 玩家能力与接入范围

新档从序章守卫战与奖励进入一次立即完成的教学派遣，再选择三区域。区域固定分支，七个共享逻辑地点、每路线四次访问；可跳过回忆，守卫胜利及领奖后主动离开。区域首次成功取得终端、兑现临时人物；重玩获得常规资源，不重复获得终端。三台终端开放三阶段终局，每场胜利后执行系统操作，最终永久恢复校园并开放结尾重看。

规则事实源：[现行设计](../game-design.md)。地图与地点采用示意布局，系统记录明确为虚拟校园事件，人物仍为样本；真实资料与正式视觉没有被本轮代码补造。
