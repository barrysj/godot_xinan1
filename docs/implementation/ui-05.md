## 玩家能力与接入范围

主菜单轮播图书馆、品学楼、秋天银杏主楼三个地点。未完成完整终局通关时显示对应异常场景；读取现有 `CampusProgress.campaign.restored` 为真后，显示对应较正常的校园图。地点每 8 秒交叉淡入切换，菜单按钮和标题由 Godot 原生组件保持可编辑。

玩家价值：在开始游戏前先看到“校园异常”的主题承诺；完成一次完整主线后，主菜单视觉反馈校园已恢复。
