# 战斗 Demo

这是用来验证战前布阵与自走棋自动战斗的临时原型，不连接正式存档。

当前为像素 2D 版：敌我上下对阵，校园庭院场景、Kenney CC0 像素角色与植被、待机起伏和攻击位移、弹道、伤害数字、治疗粒子、护盾轮廓与技能提示。角色仍使用奇幻服装占位，尚未定制同学形象。素材来源与许可证位于 `assets/pixel/kenney/`。

`pixel_battle.gd` 负责表现，继承 `battle_demo.gd` 的战斗规则与交互。战斗与正式冒险共用自动移动、索敌和射程规则。

在 PowerShell 7 中运行：

```powershell
pwsh.exe -File .\run-battle-demo.ps1
```

也可在 Godot 中按 F5，然后点击模板菜单的 Play；或打开 `scenes/battle_demo/battle_demo.tscn` 按 F6。

- 新战斗我方棋盘为空。底部卡片 hover 轻微放大，点击后抬起；再点我方空格显示半透明预览，绿色对勾确认、红色叉号取消。确认前可继续点其他空格切换位置。
- 按住卡片拖入我方空格时显示预览，松手直接部署，无需确认。拖到场外、敌方或已占用格松手不修改阵容。
- 已部署卡片可重新点选换位，或点击“撤回”。最多部署四人，四人就绪后开战。Esc 优先取消当前部署，暂停和失焦也取消未确认操作。
- 点击同学后，点击“装备”，分配唯一的篮球鞋（攻击间隔减少 25%）。
- 准备阶段点击敌阵按钮切换两种遭遇。
- 开战后全自动，每 3 次普攻附加一次技能；可以暂停或切换 1×／2×。
- 胜利后所有同学恢复完整状态；失败后点击重新编队，无限重试。
- 按 Esc / P、点击右上角“菜单”，或点击战斗中的“暂停战斗”打开暂停菜单。暂停会冻结战斗、计时、待机动作和特效。
- 暂停菜单可继续游戏、重新编队、返回主菜单、退出桌面游戏；返回主菜单与退出有确认提示，关闭窗口也走退出确认。Web 版隐藏关闭程序按钮。
- 确认框按 Esc 返回暂停菜单；菜单按钮支持 Tab／方向键焦点与 Enter 确认。当前 Demo 没有存档，返回主菜单后重新开始会使用初始阵容。

试验建议：将守护者部署在前排中间、冲刺手放前排右侧、远射手放后排左侧、应援者放后排中间，比较装备给不同同学的结果。

验证入口：`pwsh.exe -File .\run-battle-demo.ps1 -Smoke`。包含两组敌人、不同装备携带者、胜利恢复和 1×／2×结果一致性检查。

已使用本机 Godot 4.7.2 检查战斗与桌面画面。手机浏览器、Web 导出和跨平台中文字体尚未验证。当前以可玩规则为重点，尚未制作角色美术、音效、地图和成长。

## 自走棋战斗规则

- 保留六个战前布阵位；开战后双方在 7×7 逻辑场地自动行动。格距采用场景投影，射程按逻辑格的欧氏距离计算。
- 近战默认射程 1.45 格，远射手、应援者、发明家、晨光及对应远程敌人为 3.2 格；默认移速 2.4 格/秒。在人物资源中编辑 `attack_range` / `move_speed`。
- 射程内保留现有目标，没有有效目标时优先选择最近的范围内敌人；没有可攻击敌人时，用广度优先搜索寻找最近的可达攻击位置，自动绕开友军与敌军。相同距离按稳定的单位和方向顺序选择。
- 行走时保留起点和目的格的占位，不穿人、不交换穿越；受阻时等待并重算，死亡单位立即释放占位。移动结束后才能攻击，冷却在移动中恢复，但不会累积连发。
- 普攻与单体伤害技能受射程限制。后排优先按实时纵向位置判断；整排技能作用于当前目标横向带状范围（纵向差不超过半格）且在射程内的敌人。护盾作用于自身及约两格内友军；治疗与明确配置的全体技能保持全队作用域。
- 点击战场上的实际人物查看射程、移速；金线为所选人物的射程边界，虚线连接当前目标。战中点击只查看，不改变自动行动。
- 固定 0.05 秒模拟，暂停冻结位置与计时，1×／2×只改变推进速度；重新编队恢复初始位置。原有装备、技能计数、奖励和胜负结算继续生效。

这是自走棋战斗层的改造，尚未加入商店、购买合成、羁绊或经济系统。新的射程与范围会改变战斗平衡，需要后续实际游玩调优。

验证：使用 Godot `--headless --path . res://game/combat/auto_battle_check.tscn` 检查绕路、射程、死亡换目标、占位、暂停、复位与倍速；原 `--demo-smoke`、`--run-smoke` 覆盖布阵、装备和完整冒险。运行战斗场景并加 `-- --autobattle-capture` 可输出 1920×1080、2560×1440、1920×1200 的整备与战斗截图到 `.godot/`。

## 卡片部署与存档

部署交互实现于 `scenes/battle_demo/deployment_panel.gd`，范围依据 `tasks/BATTLE_DEPLOYMENT.md`。卡片来源为当前冒险 roster；Demo 使用初始四人。半透明模型使用已有角色图像，确认/取消使用简易矢量勾叉，未新增正式美术。

确认部署与撤回才修改 formation 并保存；候选格、hover、拖动为临时状态。存档允许 0～4 名部署角色，重复角色、非 roster 角色、超过四人仍拒绝。新遭遇从空棋盘开始；同一场战斗暂停、重试、恢复存档保留已确认位置。四人未部署齐时不允许开战，已有战斗结算人数规则保持不变。

交互验证：Godot `--headless --path . res://scenes/battle_demo/deployment_check.tscn -- --deployment-check`。通过真实 Viewport 输入分发测试点击确认、取消、拖动、非法落点、移动阈值、失焦、Esc、部分部署读档与整场战斗。将参数改为 `--deployment-capture` 并移除 `--headless`，可生成三种分辨率的空棋盘、点击预览、拖动预览和已部署截图。
