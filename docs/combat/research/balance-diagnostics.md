# 双流派平衡诊断

当前构筑围绕漏洞追踪／护盾反冲，数值只维护在[战斗规则](../rules.md)；机制与实施边界归[CORE-05](../core-05.md)。采用真实模拟层、固定构筑与明确策略评估资源收入／支出、组合可达性和站位敏感性，不以技能推荐或纸面算式代替主线试玩。

## 保留的数据

- [资源与平衡诊断](combat-balance-evidence.json)
- [路线压力诊断](combat-route-pressure-evidence.json)
- [起始流程诊断](combat-starting-flow-evidence.json)

204次确定性样本及两条起始流程链用于检查当时构筑，不是随机胜率，不能代表全部强化组合、最新版本或真人趣味性。原始JSON保留代码基线、输入与结果；最新回归见[验证](../verification.md)。过时技能检索、未安装候选和各轮初值提案不继续维护。

后续优先按原战役完整流程采样、明确记录失败原因，再做玩家上手和节奏试玩。技术样本通过后仍需验证60～90分钟体验、目标设备和纪念内容。
