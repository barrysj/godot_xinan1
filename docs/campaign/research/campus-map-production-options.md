# 校园地图制作方向与来源

当前采用可编辑3D母版离线渲染、运行时2D地图交互。玩家在选择下一站，地图不承担角色漫游；同一几何和正交相机输出三态，地点、路线和明暗由Godot叠层维护。这个选择控制了制作与适配成本，保留未来重渲染能力；自由视角3D暂不进入范围。

当前地图已接入原战役选区流程，不能再把此前“尚未导入／尚未接入”的调研状态当成现状。设计与实施见[地图布局](../map-layout.md)、[战役档案](../core-02.md)及[校园图](../../art/environments/campus-map.md)。详细源文件和许可证见[原始参考](../../../design/references/m1-campus-map/README.md)，当前可编辑模型与只读核验见[源包](../../../design/concepts/environments/campus-map/campus-map/asset_006/README.md)。

## 保留的来源结论

负责人提供的TopoExport DXF／GLB确有建筑网格，可作为简化校园几何起点。参考目录保留6份DXF、5份GLB、配准数据和已有导出许可；没有补造缺失的原始模型或许可。原核心导出只覆盖约974×1013米，后续已补多个分块；网格数量与非零Z不能证明完整测绘、准确楼高或所有地标身份。

诊断[截图](../../../design/references/m1-campus-map/research/dxf-inspection.png)只用于几何识别，省略树木且高差放大，不能当成正式美术候选或量测误差验收。对地图截图、导出数据、照片和最终渲染成品分别维护来源与使用边界；已有许可原文是事实源，文档整理不作新增权利判断。

## 制作与交互边界

同版三态保持几何、相机、逻辑坐标和主要地标关系；路线可通行性由战役Resource决定，不能从图片明暗推断。place_id、一次访问实例及地图落点分别管理。UI标签、选区和点击热区不烘焙进底图；布局坐标统一转换，小屏点击可用性和平台预算按实际设备验证。

只有明确需要持续视差、自由视角或几何动画时才重新评估实时3D。新状态改几何或相机须同时复核路线和锚点；当前展示不承诺实地步行导航或测绘精度。
