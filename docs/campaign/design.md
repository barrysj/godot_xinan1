## M1 现行设计：虚拟校园修复战役（2026-09-16）

本节记录本次讨论确定的设定与玩法，优先于下方历史提案。战役机制已经接入；真实纪念内容、真人体验与发布验收仍未完成，工程状态见 CORE-02。实施细化采用下述默认值，素材身份和具体地图须依真实资料确认，不以占位冒充定案。范围与降级归 [Roadmap](../roadmap.md)，美术交付清单归 [M1 静态资源清单](../art/art-02.md)。

### 世界背景与时间线

- 未来技术可构建高度定制的纯数字虚拟世界，真正上传具有连续性的人类意识，而非只复制人格。末日爆发后，人类匆忙上传，形成无数虚拟世界孤岛；本项目接受这一虚构前提，暂不展开伦理争论。
- 游戏主体发生于 2026 年技术雏形阶段：只能构建虚拟世界、复制记忆并构建毕业生虚拟人格，尚不能真正上传意识。
- 原型启动时留下未关闭的早期 AI 助手。它误解 prompt 的目标，持续自我进化，获得超级上下文、记忆与特化的存续能力，并把管理员后续开发内容视作 Bug 加以修复、回滚。
- 管理员通过当前 AI 助手构建毕业生人格，赋予修正虚拟校园的任务。人格知道自身为虚拟构建，坦然参与。具体人物根据真实资料录入；不自行虚构同学经历或排名。
- 当前引导 AI 与前代为同源新旧版本。前代难以删除，解决方案是重新解释指令、限制权限，并将它改造为记录者。
- M1 结尾只暗示记录者在遥远未来仍运行。末日、真正意识上传和虚拟孤岛是背景储备，不在本篇解释，也不声称记录者是上传技术的直接源头。

### 人物职责与叙事方式

| 身份 | 职责与表现 |
| --- | --- |
| 管理员／玩家 | 指挥、编队、选择路线和终局操作；少量对白，关键节点提供语气不同、结果一致的回应 |
| 当前 AI 助手 | 引导者、系统介绍、旁白、任务指引；与前代明确区分 |
| 前代 AI | 冲突来源与终局对象；把新内容判作错误，最终转为只读记录者 |
| 毕业生人格 | 战斗与事件参与者，承载真实共同经历；具体名单、外观和台词待资料 |
| 守卫／敌人 | 实施默认解释为前代维护、校验或回滚的代理；具体形象沿用占位直至获准制作 |

关键剧情放在序章、区域出发／Boss／结算及终局等必经处；可选随机热点不承载理解主线所必需的信息。

### 术语与整体流程

- 主线战役：序章、三个区域远征和终局的整体。
- 区域：真实校园地图缩放、简化后的固定分支图，区域可重叠。
- 地点：真实校园中的空间身份，跨区域共享名称、基础素材和定义。
- 地点访问：本局进入某地点产生的随机热点、调查、战斗、领奖及离场状态。
- 记忆终端：三个区域各自获得的可携带永久设备，在终局使用；统一使用此名称，不额外引入“锚点核心”。
- 探索等级：按持有记忆终端数量提升的局外内容开放等级；不等同角色战斗等级。

流程：短线性序章（局内教学）→ 基地一次立即完成的教学派遣 → 取得校园路线资料 → 每局选择三区域之一 → 固定路线中选择分支并探索地点 → 区域 Boss → 首次取得对应记忆终端 → 回基地。
三台齐全后可选择短终局路线。已完成区域仍可重玩，获得常规资源，终端和永久解锁不可重复领取。

### 序章与局外教学

序章教部署、自动战斗及一次奖励／事件，随后必经免费教学派遣，永久开放出发准备与校园路线。后勤人员可任选，无效果差异。所有主线派遣消耗修复资源后立即保存解锁，再播放往返演出与成果窗口；恢复和重复点击不刷奖励。具体规则见[派遣地图](../progression/dispatch-map.md)。

### 三区域地图与地点探索

- 依据用户提供的校园平面图或航拍制作；三区域合计 6～8 处独特地点，每条实际路线约访问 4～5 处。真实资料到位前允许逻辑图占位，不能声称空间关系真实。
- 地点、坐标、连线和终点固定，采用分叉与汇合、单向不可回头；遭遇组合、非关键事件及奖励随机。各区域可以共享地点，按访问上下文调整遭遇与强度。
- 每地点点击探索，2～4 个热点；一处可见守卫战，余下为照片、物件、人物或系统事件。照片和回忆始终可选，允许直接挑战。
- 离场前至少取得一次守卫战胜利。实施默认战后返回地点、可继续查看热点，再主动离开；区域终点的 Boss 满足当地战斗门槛，不额外叠加必打守卫。
- 随机内容从当前等级合格池选取，优先未记录回忆；耗尽后随机重复。一次访问抽取后保存，重开界面和续玩不重抽。
- 照片采用“简化场景＋原照热点卡”，原图可放大，附短说明。查看即永久加入图鉴回忆页，按地点显示记录进度；序章和结尾亦可重看。
- 热点可由多轮节点组成，并与其他地点／地图形成前后关联。允许返回的轮次保留未结束节点，续玩恢复原节点；全局已发现线索随原存档持久化，使用区域＋地点身份区分同名地点。当前系统热点可先记录回滚指令，再到其他地点对照；人物／记忆继续原职责，不把可选线索变成通关必需条件。
- 事件内容维护于`resources/content/events/hotspot_dialogues.json`：稳定line ID、节点、短选项、目标节点、flag／program条件、一次性标记及明确允许的效果。只有确认选择时提交节点和全局事实，重复旧节点操作不生效；开启新地点清掉本地阅读状态，已发现的全局事实保留。长文本和条件失败原因通过同一原生选择子页呈现。后续新增内容扩此图谱，不另建叙事或存档系统；现阶段没有任意脚本DSL、动态LLM剧情或新的奖励类型。
- 返回权限由事件默认值与节点覆盖值决定，维护方法见[内容录入指南](../content/authoring.md#m1多轮热点返回权限)。禁止返回时，右上按钮置灰并常显“必须完成选择”，Esc及控制器遵守同一限制；菜单保存／退出和续玩保持原节点、热点快照与已确认事实。纯导航不占事件选项，无选项的结束阅读页必须有返回出口。现有固定对话不新增随机结果；未来随机结果须在展示前冻结到原检查点，不能只靠禁止返回实现防重抽。
- 图书馆保留精制室内与照片回忆，默认四热点为照片回忆、人物事件、系统线索、守卫战。2026-10-07主战役所有地点已复用正式背景和同一热点交互；区域绑定已于2026-10-09迁入`resources/campaign/`，由`campus_presentation.gd`读取；编辑方法见[区域流程配置](flow-authoring.md)与CORE-02，故事落点仍暂定，人物／系统故事尚为虚拟样本。
- 同一地点支持多场景背景，通过“探索场景”栏、通行热点和小地图切换；通行热点在末场景成为地点出口，守卫及领奖条件不变。小地图仅表达相对位置，以颜色和文字区分楼层。所有场景共享一次地点访问和原调查／守卫／奖励状态，切换不增加站次、不重抽、不绕过离场条件。当前图书馆为四场景样例，其他地点支持配置但尚未补齐更多背景。场景配置和保存规则统一维护于[区域配置](flow-authoring.md#地点内多个场景)。

### 局内构筑、永久人物与派遣联动

- 延续自动战斗、胜利恢复、失败保留构筑并重试；局内装备与训练遵循既有规则。普通探索从已开放人物中选两人，第二、第三节点各必经一次同伴会合，逐步达到四人；终局仍以四人展开。编队与资格规则见[战斗规则](../combat/rules.md)及[CORE-02](core-02.md)。
- 永久人物资格由派遣开放，进入下次新局的出发与会合候选池。新主线不再通过可选交谈直接塞入发明家，也不靠区域通关才兑现人物。旧进行中存档保留原语义；新规则不追改已经冻结的队伍。
- 修复资源用于功能、人物资格、准备池、物品出现池和规则buff解锁，避免永久生命／攻击百分比成长。出发准备消耗本次预算并受携带格子限制，不再次花修复资源。
- 内容等级与解锁效果在新局建立时冻结，途中回基地不刷新已有内容。终端推进区域与终局，不替代人物派遣。所有派遣即刻结算，短流程不依赖现实等待或刷满数值。
### 终局、校园恢复与收尾

- 三台记忆终端集齐后开放短终局：固定前奏、整备和三节点分阶段自动战斗。
- 战斗争取修改核心存储的机会；阶段击破后进入短系统操作与对白。实施默认三步为修正目标、撤销越权、限制写入；具体文案可润色，不改变最终结果。
- 前代保留记忆和存续能力，重新理解任务，被限制为对虚拟世界只读，后续仅在记录用途下追加进程日志，不能修改／回滚被观察世界。
- 每区域首次成功后，基地对应区域渐稳；终局后校园整体恢复日常状态。回忆与恢复不会因失败倒退。
- 主线整体目标 60～90 分钟，以真人测试为准，不能靠强制读完照片或重复战斗凑时长。

### 未到位资料与实施默认的边界

实际校园图、其余两个区域名称与终点、图书馆照片、真人名单和共同经历、具体外观与逐字对白尚未提供完整版本。开发使用显式占位和稳定 ID；资料缺失只阻塞对应真实内容验收，不阻塞战役、存档和交互机制。教学细节、出发编队和终局三步措辞为实施默认；不得把它们记成用户提供的真实经历。当前已使用正式人物动画、敌人包和地点背景；未提供的真实内容继续明确占位。资产状态见 ART-02。
