# 校园战役游玩与接入

当前新档进入 M1 战役：序章 → 教学派遣 → 三区域任选顺序 → 三台记忆终端 → 三阶段终局 → 校园恢复。区域可重玩，终端和人物兑现不重复。完整实现与边界见 [CORE-02](core-02.md)，设定和规则见 [设计](design.md)。

## 入口与存档

`scenes/menu/menu.tscn` 的 Start 进入正常流程；`pwsh.exe -File .\run-debug.ps1` 使用独立调试档。启动、调试面板和即时战斗见 [Debug](../development/debug.md)。正式 profile 为 v4，构筑 ShortRun schema8，当前 Journey schema2；旧活动战役需要重开，永久档案不会因此删除。存档职责见 [SAVE-02](../progression/save-02.md)。

地点守卫战胜利并领取奖励后，玩家主动离开；失败保留构筑和战前阵位，可无限重试。中途返回保存检查点，半场战斗续玩从战前开始。暂停与菜单分开，速度支持 0.5／1／1.5／2 倍。旧五层随机短局保留为兼容与开发夹具，已经不是新档主线。

## 地点、路线与工具

原战役选路复用完整校园图的投影、缩放和拖动；只开放当前层，先预览，再“前往”。各区域流程由 `resources/campaign/` 配置，空间地标和亮区由 `game/run/expanded_campus_layout.json` 配置，两者职责见 [流程录入](flow-authoring.md) 与 [地图布局](map-layout.md)。图书馆、实验楼及其他区域复用同一热点组件和详情；真实故事落点仍须校对。

基地派遣使用已有局外地图，与战役选路不是同一数据模型。队伍、费用、离线计时和返程见 [派遣地图](../progression/dispatch-map.md)。

## 原主线出发构筑（2026-10-07）

新档序章及正式区域出发先选择追踪或护盾，说明链路并给出可调整的参考编队、核心程序与热修复。正式区域和终局可以沿用已保存队伍。取消选择返回基地，不立即替换活动局。

护盾方向在发明家未解锁时可用基础四人开局，正式区域第一站提供原人物交谈。交谈加入本局候补后，可按“采用编队”切成完整供盾队；不强制招募、不自动覆盖站位。区域成功才同时兑现永久人物与最终编队。没有新增存档系统；实际两个新档各完成序章及四站图书馆区域的证据与限制见CORE-05和battle-demo.md。

## 奖励与热点选择子页

当前M1奖励、热点事件和区域结算使用弹出子页：左边为调查／补给插画或既有记忆终端，右边为描述和选择。奖励只选一份，需指定对象时进入对象卡，返回不重抽；无适用奖励仍可继续。未满足条件的对象或事件选项显示原因。长文与较多对象支持滚动，键盘焦点会把选项带入视野。

热点允许多段交谈：每个事件及每轮节点可配置返回权限；允许返回时保存未结束的阅读位置，继续探索恢复原节点。禁止时，右上“返回地点”置灰并提示“必须完成选择”，Esc与旧热点操作也无法跳过。选项里不再出现重复的稍后调查／返回地点。记录过的回滚线索可在其他地图中引用、对照；可选调查不锁住主线。事件Esc遵守当前轮的返回权限，对象Esc返回奖励，奖励Esc打开已有菜单。菜单保存／退出、回基地续玩保持当前轮与已保存热点；现有固定对话不新增随机抽取。首次通关得到该区域已有记忆终端，收益保存成功后展示回收页；重复通关只按原规则给资源。

选择子页的阅读顺序为标题→事件记录／领取说明→可选行动／候选奖励→保存状态。故事正文采用常规字重和轻底色，选项名加粗，规则说明与限制居后。结果由图标、类别文字和颜色共同表达：道具／资源为金，属性提升为绿，属性损失为红，消耗为棕，线索／构筑为青，伙伴为品红，探索／未知为灰；混合后果逐项同时显示，长标签在卡内换行。

实际分类读取原奖励类型和事件数据，不把“攻击间隔减少”按负号推断为损失。显示层支持显式outcomes数组，但不负责执行效果；当前主线没有新增扣属性事件。悬停与键盘聚焦只强调对应卡片并轻弹结果图标，节点更新短淡入，按钮位置与点击保持稳定。详细验证及展示夹具边界归UI-02。

常见三候选采用紧凑卡：按钮与标题同排，描述全宽，后果与辅助说明合并一排；分类与主标题共用页头。三个普通奖励在目标桌面尺寸同屏显示。长故事和较多对象继续支持滚动，不裁掉规则说明。
