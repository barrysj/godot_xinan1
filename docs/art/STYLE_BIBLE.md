# Cyber Pop Campus 视觉方向

视觉基线沿用 v0.3。本文件保留跨领域的方向、配色用法、光影、VFX 与状态强度；角色、场景、UI 的具体细则分别维护在对应 Spec，不在此重复。

- [角色规范](specs/CHARACTER_SPEC.md)：比例、身份、服装、表情、动画方向与交付。
- [场景规范](specs/ENVIRONMENT_SPEC.md)：空间要素、状态与分层交付。
- [UI 规范](specs/UI_SPEC.md)：页面、组件、排版与适配。
- [执行契约](ART_CONTRACT.md)：资料职责与实现约束；生产及评审见其工作流入口。

本文件的色彩名称与比例描述用法；精确数值读取 [colors.json](../../data/visual/colors.json)，不维护第二套色板。

# 1. 一句话视觉定义

一所真实、明亮、现代的理工科校园，被学生的数字思维重新诠释。

白天，它是一所清爽、可信、充满学习与社团生活气息的电子科技校园；

夜晚，数字导视、屏幕光、玻璃反射与霓虹让它显露出更鲜明的科技气质；

异常发生时，隐藏在校园背后的数据层彻底显形，现实空间被网络节点、波形、电路线、故障信息与数字界面覆盖。

# 2. 项目视觉目标

视觉需要同时完成以下任务：

1. 一眼看出“这是校园”
2. 一眼看出“这是电子科技 / 计算机系”
3. 角色具备青春、聪明、现代、真实的学生气质
4. UI 有强辨识度，但普通功能页不过度张扬
5. 白天、夜晚、战斗、异常具有明显视觉层级
6. 日常资产适合长期观看，不造成视觉疲劳
7. 关键高潮具有足够强的赛博视觉爆发力

# 3. 核心视觉支柱

## A. 校园真实感

先是校园，再是赛博。

必须保留真实校园元素：
- 教学楼
- 教室
- 机房
- 电子实验室
- 社团活动室
- 宿舍
- 图书馆
- 食堂
- 操场
- 中庭
- 走廊 / 连廊
- 校园夜景

真实生活痕迹：
- 课程表
- 作业
- 实验报告
- 项目展示
- 竞赛海报
- 社团物品
- 学生证
- 书包
- 耳机
- 笔记本
- 水杯
- 外卖
- 便利贴
- 课本
- 线缆
- 开发板
- 路由器 / 交换机

原则：

> 科技感优先从“专业活动与空间使用痕迹”中自然生长出来。

---

## B. 计算机 / 电子科技符号系统

推荐：
- 代码片段
- 流程图
- 二进制 / 十六进制
- 电路走线
- 命令行
- 调试窗口
- 网络拓扑
- 数据流箭头
- 节点图
- 波形
- PCB 纹样
- 像素小图标
- 系统状态标签
- 项目看板

原则：

> 不要依靠大量 `010101` 来假装科技感。

---

## C. 青春校园感

角色与场景需要：
- 年轻
- 明亮
- 有个性
- 有社团文化
- 有学习压力与创造欲
- 有一点潮流与亚文化气息
- 但仍然像现实校园中的学生

---

## D. 图形设计感

日常层适度使用：
- 斜切矩形
- 锐角标签
- 大小色块
- 节点
- 电路线
- 信息卡片
- 简洁数据纹理

夜晚 / 战斗 / 异常层可明显强化：
- 大色块
- 对角切割
- 发光边缘
- 数字网格
- glitch 条带
- 大字号
- 图形化 HUD
- 数据层叠

原则：

> 日常不做满屏海报，高潮可以像一张会动的赛博海报。

---

## E. 双层世界进一步扩展为四级视觉状态

### 1. 白天日常
关键词：
- 清爽
- 明亮
- 可信
- 自然光
- 低饱和
- 留白
- 轻数字感

### 2. 黄昏 / 情绪层
关键词：
- 暖橙
- 淡粉
- 蓝紫过渡
- 青春
- 回忆感
- 情绪叙事

### 3. 夜晚 / 战斗层
关键词：
- 深蓝
- 青
- 品红
- 紫
- 屏幕光
- 玻璃反射
- 霓虹
- 更强图形节奏

### 4. 异常空间
关键词：
- 高饱和青 / 品红
- glitch
- 数据流
- UI 侵入现实
- 网络节点
- 波形
- 电路线实体化
- 错误信息
- 数字空间覆盖现实

原则：

> 玩家先认出原空间，再看到它发生异常。

# 5. 色彩系统

## 5.1 品牌核心色
- 科技青 / 电蓝
- 品红 / 洋红
- 亮黄
- 黑
- 白
- 深灰

## 5.2 白天日常层
建议比例：
- 75% 中性浅色
- 15% 青蓝
- 7% 深灰 / 黑
- 3% 品红 / 黄

关键词：
> 清爽、克制、聪明、耐看。

## 5.3 黄昏
- 暖橙
- 淡粉
- 金黄
- 蓝紫
- 青灰

用于：
- 青春
- 回忆
- 情绪
- 放学
- 关系剧情

## 5.4 夜晚
- 深蓝
- 蓝黑
- 深灰
- 电蓝
- 品红
- 紫
- 少量亮黄

夜景允许明显提高饱和度与对比。

## 5.5 异常
- 黑
- 蓝黑
- 紫黑
- 高饱和青
- 高饱和品红
- 紫
- 冷白
- 酸黄 / 荧光绿
- 错误红

异常层允许最高视觉张力。

# 6. 光影

## 白天
- 高明度
- 自然光
- 通透
- 柔和阴影
- 屏幕冷光辅助

## 黄昏
- 暖橙
- 淡粉
- 蓝紫
- 长阴影

## 夜晚
- 青 / 品红屏幕光
- 蓝黑环境光
- 玻璃反射
- 雨水反射
- 高对比局部亮点

## 异常
- 强边缘光
- 霓虹反射
- 局部过曝
- 数字光层侵入现实

# 7. VFX

## 日常
- 轻微发光
- 面板滑入
- 标签弹出
- 节点连线
- 提醒高亮

## 战斗
- 技能色块
- 数据轨迹
- 波形
- 电路线
- 像素碎片
- 节点爆发

## 异常
- glitch
- 数据噪点
- UI 重组
- 文字篡改
- 数据流
- 网络节点失控

禁止：
- 满屏持续扫描线
- 长时间读不清信息
- 每个页面都抖
- 所有东西都发光
