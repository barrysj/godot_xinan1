# Cyber Pop Campus 完整视觉圣经 v0.2

## 1. 一句话视觉定义

以**清爽、真实、现代的理工科校园**为基础，用克制的数字化图形语言体现电子科技与计算机系身份；在**夜晚、战斗、异常空间和剧情高潮**中，再释放更强烈的霓虹、赛博、数据化与故障视觉冲击。

简称：

> **清爽理工校园 × 轻数字美术 × 局部赛博强化**

视觉节奏：

> **白天耐看，夜晚提纯，异常爆发。**

---

## 2. 核心视觉原则

### A. 日常层必须“可信”
玩家首先要相信这里是一所真实存在的理工科校园。

关键词：
- 明亮
- 清爽
- 理性
- 青春
- 空气感
- 自然光
- 学习与生活痕迹
- 现代校园建筑
- 真实设备与专业环境

科技感主要来自：
- 课程内容
- 计算机与电子设备
- 投影 / 屏幕
- 代码
- 流程图
- 网络拓扑
- 电路与实验器材
- 项目海报
- 学生个人科技配饰

而不是：
- 满屏霓虹
- 满墙 010101
- 到处悬浮 HUD
- 所有东西都未来化

### B. 夜晚层允许更强风格化
夜景不是简单把白天调暗，而是进入项目更鲜明的“赛博校园”状态。

可强化：
- 青 / 品红霓虹
- 屏幕光
- 玻璃反射
- 雨夜镜面
- 公共信息屏
- 路灯与自动贩卖机
- 数字导视
- 少量漂浮 UI / 数据流
- 更锐利的图形切割

### C. 异常层允许“视觉爆发”
异常空间是项目最张扬的视觉层。

允许：
- 高饱和青 / 品红
- 强对比暗底
- 大面积发光线条
- 数据流
- UI 侵入现实
- 屏幕撕裂
- glitch
- 扭曲拓扑
- 错误信息
- 文字被篡改
- 现实结构被数字语言覆盖
- 电路、波形、网络节点实体化

但仍要求：
> **玩家先认出原空间，再看到它被异常化。**

## 3. 角色比例正式规范

### 3.1 探索 / 战斗角色：4 头身

正式锁定：

> **探索、地图、战斗、轻演出角色统一采用 4 头身。**

目标：
- 保持清晰轮廓
- 提高地图与战斗中的动作可读性
- 保留角色服装与配饰识别
- 比 Q 版更成熟
- 比 5～6 头身更适合常驻玩法画面

要求：
- 不能做成二三头身萌系 Q 版
- 头部可适度放大，但脸部不能过分幼态
- 四肢比例仍应支持自然跑、跳、攻击、交互
- 服装结构必须保留主轮廓
- 发型、角色色彩、耳机、学生证、包等识别点必须与立绘一致

### 3.2 对话 / 剧情立绘：7 头身

正式锁定：

> **对话、剧情、角色档案、宣传主视觉统一采用约 7 头身。**

目标：
- 展现青春感
- 表现服装层次
- 表现配饰
- 支撑更成熟的角色气质与情绪表达

要求：
- 与 4 头身版本保持相同人物身份
- 发型、脸部特征、服装结构、角色主色不漂移
- 不因为进入立绘就年龄突然增长很多
- 角色仍然是学生，不变成潮牌模特或赛博佣兵

### 3.3 4 头身 ↔ 7 头身一致性
必须保持：
- 发型轮廓
- 刘海结构
- 眼睛形状
- 主服装结构
- 角色色彩身份
- 核心配饰
- 学生证 / 社团标识
- 标志性鞋型 / 包型

允许简化：
- 细小挂件
- 复杂缝线
- 小面积纹样
- 袖口 / 裤脚细节

## 4. 角色总体风格

角色应该像：

> **真实校园里稍微会打扮、懂技术、有自己兴趣与社团身份的理工科学生。**

### 保留
- 精细 2D 卡通
- 清晰线稿
- 赛璐璐阴影
- 少量柔和渐变
- 黑 / 白 / 灰作为服装主基底
- 科技青 / 品红作为角色识别色
- 学生证、耳机、双肩包、智能手表、少量科技挂件

### 收敛
相较 v0.1，减少：
- 太多荧光条
- 太多高饱和拼色
- 太多潮牌式装饰
- 太多挂件
- 太多赛博贴纸
- 大面积品红 / 酸黄服装

日常服装整体应更像“学校里真的有人会穿”。

## 5. 色彩系统 v0.2

### 5.1 日常层
主基底：白、浅灰、淡蓝灰、冷白、少量浅木色、天空蓝。

主科技色：科技青 / 电蓝。

强调色：品红、亮黄。

比例建议：
- 75% 中性浅色
- 15% 青蓝
- 7% 深灰 / 黑
- 3% 品红 / 黄

关键词：**清爽、克制、聪明、耐看。**

### 5.2 夜景层
主基底：深蓝、蓝黑、深灰、黑。

强化色：电蓝 / 青、品红、紫、少量亮黄。

建议：
- 显著提高饱和度
- 增加玻璃与雨水反射
- 允许屏幕和导视成为主要光源
- 保留现实校园结构

关键词：**熟悉的校园，进入更鲜明的数字夜色。**

### 5.3 异常层
主基底：黑、蓝黑、紫黑。

主视觉：高饱和科技青、高饱和品红、紫、冷白高光、酸黄 / 荧光绿作为警告信号。

允许显著张扬。

关键词：**系统失真、现实被数据覆盖、未知层显现。**

---

## 6. 图形语言 v0.2

### 日常层
保留：少量斜切、电路线、简洁标签、节点、信息图形。

减少：大面积海报式拼贴、满屏框线、过多手写标语、所有区域同时高对比、过度躁动。

原则：
> 日常 UI 与场景要能让玩家连续看几个小时。

### 夜晚 / 异常层
可以显著增加：
- 大色块
- 对角切割
- 发光边缘
- 数字网格
- 故障条
- 数据节点
- 霓虹文字
- 信息面板叠层
- 强图形构图

---

## 7. 场景规范 v0.2

### 7.1 白天场景
优先营造：自然光、窗外校园、真实桌椅、植物、书籍、学生个人用品、屏幕与课程内容、清爽留白、空气感。

推荐：教室、机房、电子实验室、图书馆、社团活动室、宿舍、食堂、教学楼走廊、校园中庭。

白天科技感来自“真实使用”。

### 7.2 夜晚场景
夜晚允许：霓虹导视、公共信息屏、屏幕光、玻璃走廊、雨夜反射、自动贩卖机、教学楼灯带、局部数字化信息。

夜景视觉张力应明显高于白天。

### 7.3 异常场景
可将现实空间变为：数据化机房、异常图书馆、数字走廊、被波形覆盖的电子实验室、数据节点化中庭、故障教室、非现实服务器空间、现实校园与网络空间叠合。

---

## 8. UI 规范 v0.2

### 日常 UI
关键词：清爽、模块清晰、留白、青蓝主强调、品红 / 黄只做重点、少量斜切、轻数字感。

普通页面不要每屏都像宣传海报。

### 夜间 / 战斗 / 异常 UI
可以显著提高：对比、动势、霓虹、glitch、斜切、大字号、数据流、快速动画。

### UI 节奏原则
> **功能页耐看，高潮页出拳。**

---

## 9. 光影

### 白天
高明度、柔和自然光、清透空气感、屏幕冷光辅助。

### 黄昏
暖橙 / 淡粉 / 蓝紫过渡，偏青春与情绪。

### 夜晚
青 / 品红屏幕光、玻璃反射、蓝黑环境光、高对比局部亮点。

### 异常
强边缘光、霓虹反射、局部过曝、数字光层侵入现实。

---

## 10. 战斗视觉

战斗角色使用 4 头身。

战斗层可以比普通探索更张扬：
- 技能色块
- 高对比轮廓
- 数据轨迹
- 波形
- 像素碎片
- 电路线
- 节点爆发
- 大型 UI 字符

但角色本体仍保持学生身份与统一服装。

## 12. 最终视觉口号

> **白天，我们看到一所真实而清爽的理工校园。**  
> **夜晚，我们看到它的数字气质被点亮。**  
> **异常发生时，隐藏在校园背后的赛博世界彻底显形。**
