# Cyber Pop Campus 完整视觉圣经 v0.3 Consolidated

## 0. 文档定位

本文件是项目当前完整视觉规范。

项目类型：
- Godot 2D 校园游戏
- 电子科技 / 计算机系题材
- 青春群像
- 轻科幻
- 局部赛博异常

当前正式视觉方向：

> **清爽理工校园 × 轻数字美术 × 局部赛博强化**

视觉节奏：

> **白天耐看，夜晚提纯，异常爆发。**

---

# 1. 一句话视觉定义

一所真实、明亮、现代的理工科校园，被学生的数字思维重新诠释。

白天，它是一所清爽、可信、充满学习与社团生活气息的电子科技校园；

夜晚，数字导视、屏幕光、玻璃反射与霓虹让它显露出更鲜明的科技气质；

异常发生时，隐藏在校园背后的数据层彻底显形，现实空间被网络节点、波形、电路线、故障信息与数字界面覆盖。

---

# 2. 项目视觉目标

视觉需要同时完成以下任务：

1. 一眼看出“这是校园”
2. 一眼看出“这是电子科技 / 计算机系”
3. 角色具备青春、聪明、现代、真实的学生气质
4. UI 有强辨识度，但普通功能页不过度张扬
5. 白天、夜晚、战斗、异常具有明显视觉层级
6. 日常资产适合长期观看，不造成视觉疲劳
7. 关键高潮具有足够强的赛博视觉爆发力

- 宿舍

- 走廊 / 连廊

- 课程表
- 作业
- 实验报告
- 项目展示
- 竞赛海报
- 社团物品

- 节点

# 5. 角色比例正式规范

## 5.1 探索 / 地图 / 战斗：4 头身

正式锁定：

> **探索、地图、战斗、场景内轻演出统一使用 4 头身。**

目标：
- 动作读性强
- 地图中辨识度高
- 比 Q 版更成熟
- 适合长时间常驻玩法画面
- 适合跑、跳、攻击、交互等动作

要求：
- 不做二三头身萌系 Q 版
- 头部可适度放大，但面部不能过分幼态
- 四肢必须支持自然动作
- 服装主轮廓清晰
- 配饰适度简化
- 发型、主色、学生证、耳机、包等核心识别点与立绘一致

## 5.2 对话 / 剧情 / 人物资料 / 宣传：7 头身

正式锁定：

> **对话、剧情、人物档案、宣传主视觉统一使用约 7 头身。**

目标：
- 展现青春感
- 支撑服装层次
- 表现角色气质
- 提供更丰富的表情与姿态
- 适合剧情演出与角色魅力塑造

要求：
- 与 4 头身版本保持相同人物身份
- 不因进入立绘而“突然成年很多”
- 不变成潮牌模特
- 不赛博战士化

## 5.3 4 ↔ 7 头身一致性

必须保持：
- 发型轮廓
- 刘海结构
- 眼睛形状
- 脸部基础特征
- 主服装结构
- 主色与辅助色
- 鞋型
- 包型
- 耳机
- 学生证 / 社团证
- 标志性配饰

允许简化：
- 小挂件
- 复杂缝线
- 袖口小字
- 次要纹样
- 材质细节

# 6. 角色视觉规范

## 6.1 总体方向

角色首先是：

> **现代电子科技 / 计算机系校园里的学生。**

其次才拥有科技与赛博点缀。

## 6.2 脸部
- 二次元 / 卡通基础
- 不过分幼态
- 五官年轻、利落
- 眼睛有神但不过度大
- 表情自然，避免手游式固定“营业脸”

## 6.3 发型
- 现代校园感
- 有轮廓辨识度
- 可少量挑染
- 可用简单科技 / 像素风发饰
- 日常层避免大面积荧光发色

## 6.4 穿搭
推荐：
- 卫衣
- 宽松外套
- 校服改造
- 工装裤
- 百褶裙
- 运动短裤
- 球鞋
- 双肩包
- 校园 ID 挂牌

主基底：
- 黑
- 白
- 灰
- 深蓝

强调：
- 青蓝
- 品红
- 少量黄

## 6.5 科技配饰
每个主要角色建议 1～3 个：
- 耳机
- 智能手表
- USB 挂件
- 键帽挂件
- 芯片徽章
- 透明卡套
- 电路线小面积印花
- 二进制袖标
- 社团证

原则：

> 点到为止，别把学生做成移动外设柜。

## 6.6 表情系统
核心角色建议至少 12 个：
1. 微笑
2. 专注
3. 惊讶
4. 开心
5. 无语 / 吐槽
6. 思考
7. 困惑
8. 紧张
9. 生气
10. 害羞
11. 坚定

# 9. UI 视觉圣经

## 9.1 核心定义

> UI 是校园数字思维的外显，不是贴在游戏上的工具栏。

## 9.2 日常 UI
关键词：
- 白 / 浅灰基底
- 青蓝主强调
- 留白
- 稳定
- 清晰
- 少量斜切
- 少量电路线与节点

品红与黄：
- 只用于关键提示
- 不做大面积常驻

## 9.3 夜晚 / 战斗 / 异常 UI
允许：
- 深色底
- 青 / 品红
- 发光边
- 大色块
- 快速切入
- glitch
- 数据流
- 波形
- 大字号
- 节点连线
- 更强斜切

原则：

> **功能页耐看，高潮页出拳。**

## 9.4 核心页面

### 首页
- 主视觉
- 今日事项
- 校园动态
- 主导航
- 剧情 / 学习 / 探索 / 社团入口

### 课程表
- 真正可用
- 清晰时间轴
- 课程色块
- 今日 / 本周重点

### 任务板
- To-do / Kanban / Sprint 语言
- 主线 / 支线 / 日常
- 进度清晰

### 关系网
- 人物 = 节点
- 普通关系 = 青
- 亲密 / 情绪 = 品红
- 可行动事件 = 黄
- 网络拓扑语言

### 校园地图
- 俯视或轻等距
- 建筑清楚
- 路径清楚
- 不做信息噪音

### 对话
- 7 头身立绘
- 选项清晰
- 重大分支可强化图形节奏
