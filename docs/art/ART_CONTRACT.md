# Cyber Pop Campus 美术执行契约 v0.3

本文件是 Codex 高频读取的精简视觉契约。

## 1. 核心方向

> **清爽理工校园 × 轻数字美术 × 局部赛博强化**

视觉节奏：

> **白天耐看，夜晚提纯，异常爆发。**

视觉优先级：

1. 校园真实感
2. 电子科技 / 计算机系身份
3. 数字化图形语言
4. 夜晚 / 战斗 / 异常赛博强化

禁止：
- 低像素主导
- Q 版主导
- 廉价二次元手游风
- 硬核脏乱赛博朋克
- 企业后台式 UI
- 学生赛博佣兵化

## 2. 角色比例

正式锁定：
- 探索 / 地图 / 战斗：**4 头身**
- 对话 / 剧情 / 人物资料 / 宣传：**7 头身**

不得自行改变。

## 3. 日常层

要求：
- 明亮
- 清爽
- 真实校园
- 留白
- 青蓝轻科技点缀
- 品红与黄少量使用

科技感应来自：
- 设备
- 课程
- 代码
- 投影
- 网络
- 实验
- 项目
- 数字校园系统

禁止：
- 持续 glitch
- 满屏霓虹
- 高密度海报拼贴

## 4. 夜晚层

允许明显强化：
- 青 / 电蓝
- 品红
- 紫
- 屏幕光
- 玻璃 / 雨水反射
- 霓虹
- 数字导视
- 更强斜切与数据 UI

## 5. 战斗 / 异常层

允许最高视觉强度：
- 高饱和青 / 品红
- glitch
- 数据流
- 波形
- 网络节点
- 电路线实体化
- UI 侵入现实
- 文本篡改
- 强对比暗底

前提：

> 原空间与角色身份仍应可辨识。

## 6. UI

日常功能页：
- 清爽
- 稳定
- 可读
- 留白

战斗 / 夜晚 / 异常页：
- 可增加大色块
- 斜切
- 发光边
- glitch
- 数据流
- 快速动效

原则：

> **功能页耐看，高潮页出拳。**

## 7. Visual Token

品牌色与视觉参数优先从 `data/visual/` 获取。

有 Token 时：
- 不重复硬编码
- 不创建平行色板
- 不自行改品牌色

## 8. 资产政策

最终资产以：
`docs/art/asset_manifest.yaml`

为准。

默认只使用：
`status: approved`

禁止：
- 擅自重画
- 擅自替换
- 无指示生成新正式资产
- 根据个人审美重做 UI
- Manifest 已有元数据时重复视觉分析

## 9. 实现政策

优先：
- Godot Theme
- 共享组件
- Visual Token
- Container / Anchor
- 现有系统复用

避免：
- 平行 UI 系统
- 重复硬编码
- 无关重构
- 临时测试值遗留

## 10. STYLE_BIBLE 读取条件

只在：
- 新视觉系统
- 新场景大类
- 新角色表现体系
- 全局重构
- 用户明确要求

时读取完整 `STYLE_BIBLE.md`。

普通任务禁止默认读取全文。
