# Cyber Pop Campus 美术执行契约 v0.2

Codex 高频读取文件。

## 1. 核心风格
当前正式视觉方向：
> **清爽理工校园 × 轻数字美术 × 局部赛博强化**

视觉节奏：
> 白天耐看，夜晚提纯，异常爆发。

## 2. 角色比例
正式锁定：
- **探索 / 地图 / 战斗：4 头身**
- **对话 / 剧情立绘：7 头身**

不得自行改变比例。

## 3. 日常层
必须：明亮、清爽、真实校园、青蓝轻科技点缀、有留白。
科技感来自实际设备、课程、代码、实验与校园数字系统。

限制：品红与黄少量使用；不允许持续 glitch；不允许满屏霓虹；不允许高密度海报拼贴。

## 4. 夜晚层
允许显著强化：电蓝 / 青、品红 / 紫、霓虹、屏幕光、玻璃 / 雨水反射、数字导视、数据 UI。

## 5. 异常层
允许最高视觉强度：高饱和青 / 品红、强对比暗底、glitch、数据流、UI 侵入现实、电路 / 节点 / 波形实体化、错误信息、数字空间覆盖现实。

前提：**原现实空间仍应可辨识。**

## 6. UI
普通功能页：清爽、稳定、耐看。
战斗 / 异常 / 高潮页：允许更强斜切、大色块、霓虹、动态、glitch。

原则：**功能页耐看，高潮页出拳。**

## 7. 资产实现
- 最终资产以 `asset_manifest.yaml` 为准
- 默认只使用 approved
- 不重画
- 不擅自重新设计
- 不擅自提高日常层张扬度
- 不擅自降低异常层视觉冲击

## 8. Token
普通任务不默认读取完整 STYLE_BIBLE。只有视觉系统新增 / 重构时才读取全文。
