# 角色视觉执行规范 v0.2

## 1. 正式比例

### 探索 / 战斗角色
**4 头身**

适用：地图、探索、战斗、场景内轻演出。

要求：
- 轻卡通，但非 Q 版
- 头部不过度幼态
- 四肢支持自然动作
- 主服装结构可读
- 发型 / 主色 / 核心配饰与 7 头身版本一致

### 对话 / 剧情立绘
**7 头身**

适用：对话、人物资料、剧情演出、宣传主视觉、角色 CG 参考。

要求：青春、自然、学生感；不过度模特化；不赛博战士化。

## 2. 角色整体风格
关键词：真实学生、理工校园、现代穿搭、精细 2D 卡通、赛璐璐、克制科技配饰。

服装主基底：黑、白、灰、深蓝。
角色强调色：青蓝、品红、少量黄。

## 3. 科技配饰
每个主要角色建议 1～3 个：耳机、智能手表、学生证、USB / 键帽挂件、芯片徽章、社团证、透明卡套、小面积线路纹样。

## 4. 4 头身简化规则
可以简化：小挂件、缝线、细小文字、次要材质纹理。
必须保留：发型轮廓、主服装色块、鞋型、包型、核心识别配饰、角色主色。

## 5. 战斗表现
4 头身角色允许更夸张 Pose、更明确动作剪影、更强技能色块与数据轨迹，但角色本体不做装甲化。
