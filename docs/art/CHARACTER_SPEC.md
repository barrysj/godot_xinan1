# 角色视觉执行规范

## 总体方向
角色首先是学生，其次才带科技与赛博表达。

## 地图角色
- 4.5～5.5 头身
- 精细卡通、轮廓清晰、非 Q 版
- 通过发型、服装色块、配饰做远距离识别
- 骨骼动画为主，关键动作可补帧

## 对话立绘
- 6.5～7.5 头身
- 默认半身，重要角色可全身
- 核心角色建议 12 个表情：微笑、专注、惊讶、开心、无语、思考、紧张、生气、害羞、坚定、困惑、异常状态

## 服装
推荐：校服改造、卫衣、宽松外套、工装裤、百褶裙/运动短裤、球鞋、背包、学生 ID。

## 科技配饰
主要角色建议 1～3 个：耳机、智能手表、USB/键帽挂件、芯片徽章、透明卡套、电路图印花、社团证。

## 角色色彩身份
每个主要角色：1 个主角色色 + 1 个辅助色 + 1 个中性色。禁止每人同时使用全部品牌高饱和色。

## 命名建议
```text
characters/<character_id>/
  portrait_default.png
  portrait_happy.png
  portrait_angry.png
  portrait_thinking.png
  fullbody_default.png
  map_idle.png
```

## 交给 Codex 的元数据
Manifest 尽量记录：路径、分辨率、透明、anchor、用途、状态、裁切、是否允许变色。
