# 角色视觉执行规范 v0.3

## 1. 正式比例

### 探索 / 地图 / 战斗
**4 头身**

适用：
- 地图探索
- 战斗
- 场景内轻演出
- 小型互动

要求：
- 轻卡通
- 非 Q 版
- 不幼态过头
- 动作读性强
- 发型 / 主色 / 服装 / 核心配饰与 7 头身一致

### 对话 / 剧情 / 人物资料 / 宣传
**7 头身**

要求：
- 青春
- 自然
- 学生感
- 服装层次清楚
- 配饰完整
- 不模特化
- 不赛博战士化

## 2. 4 ↔ 7 头身一致性

必须保持：
- 发型轮廓
- 刘海
- 眼睛形状
- 脸型
- 主服装结构
- 主色
- 鞋型
- 包型
- 耳机
- 学生证
- 标志性配饰

## 3. 角色总体风格

角色首先像：
> 现代电子科技 / 计算机系学生

其次才体现：
> 轻数字 / 轻赛博审美

## 4. 脸部
- 年轻
- 利落
- 二次元 / 卡通基础
- 不过度大眼
- 不过度幼态

## 5. 发型
- 现代校园
- 有轮廓识别度
- 可少量挑染
- 日常避免大面积荧光色

## 6. 服装
推荐：
- 卫衣
- 宽松外套
- 校服改造
- 工装裤
- 百褶裙
- 运动短裤
- 球鞋
- 双肩包
- 学生 ID

主基底：
- 黑
- 白
- 灰
- 深蓝

强调：
- 青蓝
- 品红
- 少量黄

## 7. 科技配饰
每个主角 1～3 个即可：
- 耳机
- 智能手表
- USB
- 键帽挂件
- 芯片徽章
- 透明卡套
- 社团证
- 小面积电路线纹样

## 8. 4 头身简化规则

可简化：
- 小挂件
- 缝线
- 次要文字
- 材质纹理

必须保留：
- 发型
- 主色块
- 鞋
- 包
- 耳机
- 学生证
- 核心识别符号

## 9. 表情系统
核心角色建议至少 12 个：
- 微笑
- 专注
- 惊讶
- 开心
- 无语
- 思考
- 困惑
- 紧张
- 生气
- 害羞
- 坚定
- 异常状态

## 10. 动画建议

地图 / 战斗：
- 骨骼动画为主
- 关键动作补帧
- Pose 可适度夸张

立绘：
- 差分
- 眨眼
- 嘴部
- 发梢
- 肩部
- 手势

## 11. 文件命名建议

```text
characters/<character_id>/
  portrait_default.png
  portrait_happy.png
  portrait_angry.png
  portrait_thinking.png
  fullbody_default.png
  map_idle.png
  map_walk.png
  map_run.png
  map_battle_idle.png
```

## 12. Manifest 必要字段

尽量记录：
- file
- type
- resolution
- transparent
- anchor
- crop_mode
- usage
- style_layer
- status
- recolor_allowed
