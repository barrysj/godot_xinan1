# 地点场景切换与小地图

沿用校园数字界面、共享 CampusUi 与视觉 Token。左下栏以“探索场景”为标题，宽度随内容收拢，超出画板才滚动；没有上一处／下一处按钮。场景名称为短对象名，当前场景以加粗轮廓和地图圆环标识；楼层使用稳定颜色与文字双重编码。小地图默认显示所有场景，可筛选单层，不承担角色漫游或校园路线选路。

现用 `asset_002`：新增 128×128 门形通行 SVG，继承 32×32 场景图标；源文件、制作依据和交付预览见 [源包](../../../design/concepts/ui/place-scenes/asset_002/generation.md)，实际运行文件和接入由 [Manifest](../../../assets/art/manifests/place_scenes.yaml) 登记。2026-10-11 用户明确授权本资源无需审批，随后要求增加通行热点；保留 review 表示没有独立人工视觉验收，不阻塞本次授权交付，也不更改其他资产状态。

通行热点由原生 Godot Marker2D 布局定位，旧无布局场景仍使用画板右侧默认位置；图标与目的地名称共用完整点击区域。后续场景按配置顺序推进，最后场景为地点出口；普通地点出口返回路线图，区域末站走原结算，教学出口回基地。封锁出口降低亮度并叠加锁图形，原因放在悬停提示，不写进按钮。已完成／禁用热点停止浮动，普通热点降低浮动幅度；按压回弹、背景交叠、详情淡入和完成提示沿用现有动画 Token。小地图加大名称、联动悬停、白色当前位置圆环，并显示实际顺序通路；底部离场入口使用次级原生样式。

本次为现有资产的程序布局与反馈优化，未新增背景或替换 SVG，asset_002 的源包预览保留为该资产交付基线；最新运行证据见战役验证页。短提示音由 exploration_feedback.gd 程序合成，复用 Master 音量，不代表完整环境音频系统已完成。

运行入口为 `scenes/expedition/place_scene_navigation.gd`，接入原 `exploration_board` 和 `campaign_panel`。复用图书馆外景与三张室内图，未新增或替换背景。地点场景的录入、验证与边界见 [区域配置](../../campaign/flow-authoring.md) 和 [CORE-02](../../campaign/core-02.md)。
