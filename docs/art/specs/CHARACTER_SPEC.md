# 角色视觉规范

比例与角色细则沿用 v0.3；总体风格与状态强度见 [STYLE_BIBLE.md](../STYLE_BIBLE.md)，生产与批准见[美术工作流](../pipeline/WORKFLOW.md)。

## 1. 正式比例

### 探索 / 地图 / 战斗
**4 头身**

适用：
- 地图探索
- 战斗
- 场景内轻演出
- 小型互动

要求：
- 轻卡通
- 非 Q 版
- 不幼态过头
- 动作读性强；四肢支持自然跑、跳、攻击与互动，轻卡通但不做二三头身萌系 Q 版
- 发型 / 主色 / 服装 / 核心配饰与 7 头身一致

### 对话 / 剧情 / 人物资料 / 宣传
**7 头身**

要求：
- 青春
- 自然
- 学生感
- 服装层次清楚
- 配饰完整
- 不模特化
- 不赛博战士化；与 4 头身版本保持年龄感，不因进入立绘突然成年

## 2. 4 ↔ 7 头身一致性

必须保持：
- 发型轮廓
- 刘海
- 眼睛形状
- 脸型
- 主服装结构
- 主色
- 鞋型
- 包型
- 耳机
- 学生证
- 标志性配饰

## 3. 角色总体风格

角色首先像：
> 现代电子科技 / 计算机系学生

其次才体现：
> 轻数字 / 轻赛博审美

## 4. 脸部
- 年轻
- 利落
- 二次元 / 卡通基础
- 不过度大眼
- 不过度幼态；眼睛有神，表情自然，避免固定的营业式表情

## 5. 发型
- 现代校园
- 有轮廓识别度
- 可少量挑染或简单科技／像素风发饰
- 日常避免大面积荧光色

## 6. 服装
推荐：
- 卫衣
- 宽松外套
- 校服改造
- 工装裤
- 百褶裙
- 运动短裤
- 球鞋
- 双肩包
- 学生 ID

主基底：
- 黑
- 白
- 灰
- 深蓝

强调：
- 青蓝
- 品红
- 少量黄

## 7. 科技配饰
每个主角 1～3 个即可：
- 耳机
- 智能手表
- USB
- 键帽挂件
- 芯片徽章
- 透明卡套
- 社团证
- 小面积电路线纹样、二进制袖标

## 8. 4 头身简化规则

可简化：
- 小挂件
- 缝线
- 次要文字
- 材质纹理

必须保留：
- 发型
- 主色块
- 鞋
- 包
- 耳机
- 学生证
- 核心识别符号

## 9. 表情系统
核心角色建议至少 12 个：
- 微笑
- 专注
- 惊讶
- 开心
- 无语
- 思考
- 困惑
- 紧张
- 生气
- 害羞
- 坚定
- 异常状态

## 10. 动画建议

地图 / 战斗（视觉制作方向，不代表引擎已有对应后端）：
- 骨骼动画为主
- 关键动作补帧
- Pose 可适度夸张

立绘：
- 差分
- 眨眼
- 嘴部
- 发梢
- 肩部
- 手势

当前战斗实际使用序列帧与图集，尚无骨骼后端；接入与试产预算以[战斗动画](../../battle-animation.md)为准，不因上述视觉建议更换技术路线。

## 12. 制作与检查

主角组按任务需要准备：7 头身全身设定、半身立绘、表情表、配饰拆解、4 头身探索／战斗参考；日常服为基础，活动／季节服和异常版本可选，不一次性扩大产量。

检查学生与专业身份、科技元素自然度、4 头身是否幼态过度、7 头身是否保持同一人物；不得学生佣兵化。通用格式与 Manifest 字段统一见[工作流的资产检查](../pipeline/WORKFLOW.md#3-资产检查与登记)。
