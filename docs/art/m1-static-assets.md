## 本轮约束与交付责任

- 用户明确要求：不要生成任何带动画的美术资产，动画工作流仍在调整。开发中仅使用空占位符或静态资源。
- 禁止新制动作图集、序列帧、骨骼动画、动画特效、GIF／视频资产；不开展动画工作流改造。现有动画文件保留，M1 新流程用静态表现或空占位，不以删除既有资产实现限制。
- 自动战斗的模拟、阶段和伤害逻辑仍可运行；静态显示不能改变出手、命中、暂停和倍速语义。
- 可生成静态场景、立像、头像、终端图标和 UI 图片；简单界面优先 Godot 原生组件。概念、资产、接入分别评审；需要提前试接入时依工作流记录具体授权。
- 独立美术工作分支使用 art/<小写-kebab-case主题>；M1 综合功能开发分支使用 codex/ 前缀。
- 每项生成后立即更新下表，登记实际路径、对象 ID、具体版本、生成要求、用途、批准／接入状态及截图证据；未生成项不写入实际资产 Manifest。
- 每个功能完成后向用户交付当次新增和剩余清单；M1 功能开发结束时在聊天给出累计“已生成／已复用／待生成／待用户提供”及生成要求，不只丢一个文件链接。
