# 场景视觉执行规范

## 核心原则
现实校园空间结构 + 图形化科技表达 + 可切换的日常/异常双层状态。

## 核心场景
- **教室**：自然光、投影/代码/流程图、真实课堂痕迹。
- **机房**：屏幕冷光、代码/调试界面、真实设备、编号与网络元素。
- **社团室**：白板、便利贴、项目海报、原型设备、旧硬件和线材。
- **宿舍**：电脑桌搭、键盘、外卖/零食/水杯、贴纸与生活杂物。
- **校园夜景**：路灯、公告屏、玻璃反射、自动贩卖机、雨后地面、局部霓虹。

每个重要场景至少放 2～3 个专业识别点：代码投影、算法书、电路走线、网络拓扑、调试屏、实验设备、项目海报、数据图表。

## 异常层
同一场景异化，不是换地图。允许青/品红光加强、UI 浮层、数据线/节点、屏幕扭曲、文本篡改、局部 glitch。禁止只靠整屏调紫或故障滤镜。

## 命名
```text
backgrounds/<scene_id>/day.png
backgrounds/<scene_id>/evening.png
backgrounds/<scene_id>/night.png
backgrounds/<scene_id>/anomaly.png
```
