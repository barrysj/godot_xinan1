# 场景视觉执行规范 v0.2

## 1. 总原则
> **白天真实清爽，夜晚霓虹提纯，异常空间彻底数字化。**

## 2. 白天场景
核心：真实校园、自然光、空气感、清爽留白、真实设备、专业使用痕迹。
科技感来源：代码、课程投影、网络设备、电子仪器、项目海报、实验台、学生电脑、信息屏。

禁止：满屏霓虹、全空间悬浮 HUD、大量 glitch、过度高饱和撞色。

## 3. 夜晚场景
允许明显强化：青 / 品红灯光、玻璃反射、雨水镜面、信息屏、自动贩卖机、校园数字导视、夜间机房屏幕光、少量悬浮信息。

夜景可以张扬，但仍应是现实校园。

## 4. 异常空间
异常层视觉强度最高。

推荐：现实空间数据化、屏幕内容失真、电路线发光、波形悬浮、网络节点侵入、数据瀑布、错误提示、文字篡改、结构重复 / 错位、高饱和青 / 品红。

适合：夜间机房、图书馆、教学楼走廊、雨夜中庭、电子实验室、教室、服务器空间。

## 5. 异常层红线
不要：只套紫色滤镜、全屏模糊 glitch、失去原空间辨识、把所有异常场景做成同一个霓虹机房。
