# 美术任务：M1 关键记忆载体

状态：概念方向已批准；`asset_002` 与重新设计 `concept_003` 已否决；新方向候选 `concept_004` 待人工概念评审。内部规则 ID 沿用 `m1_memory_artifact`；“关键记忆载体”是本任务工作称呼，不修改全局术语、存档或玩法规则。

## 目标与范围

- 用途、数量与本次要求：为三个区域首次通关获得、终局使用的三件同源永久记忆载体设计一张推荐概念母版；本轮只生成 1 张概念候选，不制作三款正式资产。
- 对应规范、已有身份参考：`docs/art/STYLE_BIBLE.md` 的异常层与局部赛博强化；`docs/art/ART_CONTRACT.md`；`docs/art/WORKFLOW.md`；`docs/art/m1-static-assets.md`；`data/visual/colors.json` 的 anomaly 色组；`docs/art/specs/UI_SPEC.md` 的图标简洁、图形化和避免复杂拟物要求。
- 目标 Godot 场景、入口与依赖：本轮无 Godot 场景、无运行时入口、无接入依赖；后续需由负责人分别批准概念、具体资产和接入效果。
- 不在本次范围内的内容：不画日常校园背景；不制作普通调查兴趣点、终端 UI、触摸设备、落地机柜或屏幕；不添加量子物理剧情、道具名称、终局文本、新玩法、动画、三件正式变体或主游戏接入。

## 当前版本与方案

- 当前使用版：无正式生效版本；未接入。
- 已批准概念方向：对象 `m1_memory_artifact`，概念版本 `concept_001`；2026-09-18 负责人明确回复“方向通过”，同时要求完整核心保持对称或中心对称，并在正式资产阶段图形化简化、降低写实材质与微细节、加强“记忆分层／存储切片”身份。
- 已否决正式资产候选：`asset_002`，文件位于 `design/concepts/m1-memory-artifact/m1_memory_artifact/002/`，阶段为资产，`unselected + rejected + not_integrated`。2026-09-18 负责人明确反馈“这一版我不喜欢”，该版本不用于后续生产种子。
- 已否决重新设计：`concept_003`，文件位于 `design/concepts/m1-memory-artifact/m1_memory_artifact/003/`，阶段为概念，`unselected + rejected + not_integrated`。负责人指出它太像服务器，要求淡化存储，强化终端、核心与珍贵感。
- 待评审新方向：`concept_004`，文件位于 `design/concepts/m1-memory-artifact/m1_memory_artifact/004/`，阶段为概念，`unselected + pending + not_integrated`。
- 推荐方案：**全息回响终端**。主体是一枚完整、光滑的悬浮球形核心，球内悬着一枚与外壳分离的数字珍珠；一块宽大的弧形全息屏直接从球体中展开并穿过球体，屏幕中的朦胧人物回声和重叠快照只暗示记忆，不展示现实存储结构。第一眼是会回应、可交互的终端，第二眼是珍贵完整的核心，记忆身份退居内容层。
- 设计诊断：`concept_003` 将“记忆分层”直接物化成三片晶片，导致存储机制压过道具身份，整体像服务器／数据匣。新方案接受虚拟世界不必遵循现实物理，以不可能投影关系强化终端性；珍贵感来自单一完整核心、克制留白和内部珍珠光，而不是复杂材质或零件数量。
- 视觉系统：正面、严格左右对称；轮廓只保留完整圆球和一块宽弧屏；深色球壳半透明、分件极少，赤道仅一条接缝；全息屏允许三组大块模糊回声，但禁止文字、图表、密集 HUD 和可辨识人物。禁止服务器、存储架、晶片、宝石切面、水晶球、眼球、摄像头、无人机、反应堆、物理显示器与底座。
- 被否决版本的尝试：`asset_002` 将中央裂面改为完整的正面轴对称／中心对称菱形终端，外部断开模块成对布置；删除波形屏、细轨道和多数小节点，以三层宽大的透明存储切片承担“记忆分层”身份；材质改为更平整的赛璐璐色块并保留克制青黑与镜像品红。该具体造型不再继续，但“完整核心、图形化简化、记忆分层”的既有方向约束仍保留。
- 与普通调查兴趣点的区别：普通调查对象可采用校园内常规屏幕、触摸设备或机柜；本候选没有现实支架、投影器、键盘或底座，全息屏直接穿过悬浮球核展开，关闭后可完全收回核心，依靠不可能几何关系识别为虚拟世界关键终端。
- 三件后续差异预留：共享球体比例、内部珍珠和弧屏展开方式，通过屏幕外轮廓、记忆回声构图、赤道接缝节奏和球壳透明窗口形状区分；不以简单换色或添加小图标代替设计。其余两个区域身份尚未确定，当前不擅自绑定具体符号。
- 复用的批准方向／资产及原评审记录：复用项目现行 `Cyber Pop Campus` 总方向和 anomaly 色组；无现有关键记忆载体资产可复用；无历史批准记录。
- 技术依据：方形概念展示图，实际尺寸与像素格式以生成文件检查为准；本轮不声明正式图标尺寸、透明度、锚点或 Godot 显示裁切。
- 接入要求：纯概念资产，本轮删除接入实施项；后续若概念批准，再按实际 UI／结算展示区域确定正式尺寸、裁切、安全区与接入截图。
