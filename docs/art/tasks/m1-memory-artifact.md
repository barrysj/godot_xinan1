# 美术任务：M1 关键记忆载体

状态：概念方向已批准；正式资产候选 `asset_002` 待人工批准。内部规则 ID 沿用 `m1_memory_artifact`；“关键记忆载体”是本任务工作称呼，不修改全局术语、存档或玩法规则。

## 目标与范围

- 用途、数量与本次要求：为三个区域首次通关获得、终局使用的三件同源永久记忆载体设计一张推荐概念母版；本轮只生成 1 张概念候选，不制作三款正式资产。
- 对应规范、已有身份参考：`docs/art/STYLE_BIBLE.md` 的异常层与局部赛博强化；`docs/art/ART_CONTRACT.md`；`docs/art/WORKFLOW.md`；`docs/art/m1-static-assets.md`；`data/visual/colors.json` 的 anomaly 色组；`docs/art/specs/UI_SPEC.md` 的图标简洁、图形化和避免复杂拟物要求。
- 目标 Godot 场景、入口与依赖：本轮无 Godot 场景、无运行时入口、无接入依赖；后续需由负责人分别批准概念、具体资产和接入效果。
- 不在本次范围内的内容：不画日常校园背景；不制作普通调查兴趣点、终端 UI、触摸设备、落地机柜或屏幕；不添加量子物理剧情、道具名称、终局文本、新玩法、动画、三件正式变体或主游戏接入。

- 当前使用版：无正式生效版本；未接入。
- 已批准概念方向：对象 `m1_memory_artifact`，概念版本 `concept_001`；2026-09-18 负责人明确回复“方向通过”，同时要求完整核心保持对称或中心对称，并在正式资产阶段图形化简化、降低写实材质与微细节、加强“记忆分层／存储切片”身份。
- 本轮正式资产候选：`asset_002`，文件位于 `design/concepts/m1-memory-artifact/m1_memory_artifact/002/`，阶段为资产，`unselected + pending + not_integrated`。
- 推荐方案：**悬浮记忆棱核**。中央为有明确中央切面的半透明青色记忆棱核，外侧由三段彼此断开的深色悬浮弧片组成通信环；细青色信号桥、节点和少量透明全息层表达未知科技／量子通信／记忆分层。主体依赖中央核心和断开环片识别，不依赖文字或动画。
- 本轮改动、需保留的部分与当前待决事项：`asset_002` 将中央裂面改为完整的正面轴对称／中心对称菱形终端，外部断开模块成对布置；删除波形屏、细轨道和多数小节点，以三层宽大的透明存储切片承担“记忆分层”身份；材质改为更平整的赛璐璐色块并保留克制青黑与镜像品红。待负责人判断该具体正式资产版本是否通过。
- 与普通调查兴趣点的区别：普通调查对象可采用校园内常规终端／兴趣点表现；本候选没有机柜、屏幕、触摸面板、键盘、按钮或借阅设备，而是无接触悬浮、中央裂面核心和不可能几何通信环，缩小后仍以独立轮廓识别。
- 三件后续差异预留：通过核心切面方向、弧片数量／断裂关系、悬浮层结构和局部几何语法区分；不以简单换色代替设计。
- 复用的批准方向／资产及原评审记录：复用项目现行 `Cyber Pop Campus` 总方向和 anomaly 色组；无现有关键记忆载体资产可复用；无历史批准记录。
- 技术依据：方形概念展示图，实际尺寸与像素格式以生成文件检查为准；本轮不声明正式图标尺寸、透明度、锚点或 Godot 显示裁切。
- 接入要求：纯概念资产，本轮删除接入实施项；后续若概念批准，再按实际 UI／结算展示区域确定正式尺寸、裁切、安全区与接入截图。
