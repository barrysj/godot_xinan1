| 当前 asset_002 动作 | 实际制作链 | 边界 |

## 有效研究结论

- 优先职业原配模型和开源动作，原配连续蒙皮比自行拼刚性身体／手摆关节更可靠；远射／双匕首使用 Ranger／Rogue，不能把所有职业都改自骑士。
- 水平正交镜头先锁定；俯拍会与其他角色视角冲突。全身日系转绘结合已批准 2D 身份，可改善低模画风；单独换头会破坏比例与画法一致性。
- 3D 导向先表达盾牌承重、躯干冲击与施法装备展开，2D 转绘再锁脸、服装、手脚和武器特征；身份正确与动作正确都须查看。
- 比例校准使用固定脚底与整帧尺度，不逐帧包围盒归一化。首尾复用待机有助于收招；源姿势错误仍须回到模型／转绘处理。
- 游戏继续播放 2D SpriteFrames，共享状态机负责真实出手、受击、濒危、退场；程序特效跟随真实事件。未完成可把最终画面直接套在运行时 3D 模型上的方案。

首选生产规则已进入[美术工作流](../WORKFLOW.md#人形动画生成友方敌方首选)，适用于友方与敌方。H3／即梦视频、Godot 分层骨骼、Spine 等研究保留为替代路线的文字结论，非当前必经步骤；来源与许可证调研见[方法研究](../../research/guard-animation-methods.md)。
