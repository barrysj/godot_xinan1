# 合照全息卡 · 001

状态：候选待人工评审；用户已授权独立 Godot 试制，概念／正式资产／接入效果均未批准。版本根目录：`design/concepts/class-photo-holo-card/card/001`。

## 目标与选定实现

使用用户提供的班级合照，保留每个人和全图构图，制作可交互校园记忆卡；仅设计卡框和文案，不辨认人物，不推断学校、年份或身份。标题“那年 · 我们”为候选文案。使用项目字体、青色与深色基调，金属虹彩限定在框缘。

用户原话：“现在请你尝试使用这张图来制作一张godot兼容的卡。你需要新开工作树和新的分支”。因此试接入仅限新工作树中的独立预览，不自动替换游戏图鉴或奖励 UI。后续用户要求效果复用：照片／文字作为 Resource，卡框、shader 和交互作为通用组件。

## 来源与制作

原始 JPEG 字节保持一致，SHA256 本地比对通过；没有上传外部生图服务、重绘或抠取人物。原照含真实同学，后续公开发布前应由负责人确认使用和公开范围。

Godot 原生排版输出 RuiC 四图层，调用固定版本 RuiC 构建器、验证器和导出器，再由包装器调整比例和照片材质；Blender 4.5.14 LTS 实际生成 card.blend、front/left/right 渲染。Godot 使用单独 CanvasItem 实现，GLB 仅作几何参考，并非自动迁移 Cycles 节点。
