# UI 视觉与实现规范

## 核心定位
UI 是“学生面对的数字校园系统 + 强图形设计语言”，不是企业后台。

## 页面类型
- 首页：主视觉、今日事项、校园动态、主导航。
- 课程表：实用优先，清晰区分课程与今日重点。
- 任务板：可借鉴 To-do/Kanban/Sprint，但文案与状态必须校园化。
- 关系网：头像=节点；普通关系=青；情绪/亲密=品红；可行动事件=黄。
- 校园地图：俯视/轻等距，建筑图标化但可读。
- 对话：角色立绘与选项共构图，重大分支可强化色块与动效。

## 组件规则
- 标题：粗体、几何、可斜切；强视觉只用于一级层级。
- 按钮：selected/hover/disabled 差异明确，高亮优先黄或品红。
- 卡片：控制圆角，品牌形状优先锐角/斜切。
- 图标：简洁、图形化，可少量像素化，避免复杂拟物。

## 响应式
至少验证 1920×1080、2560×1440、16:10。优先使用 Container / Anchor / Theme，图片裁切策略写入 Manifest。

## 动效
常规反馈 120～220ms。推荐滑入、擦除、对角展开、标签弹出、节点连线。禁止持续运动、长时间 glitch 和阻塞操作的动画。
