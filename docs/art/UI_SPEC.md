# UI 视觉与实现规范 v0.2

## 1. UI 总方向
> **日常页清爽克制，战斗 / 夜晚 / 异常页释放赛博张力。**

## 2. 日常 UI
关键词：白 / 浅灰基底、青蓝主强调、清晰信息层级、留白、少量斜切、少量节点 / 电路线、品红 / 黄只做关键提示。

禁止：每屏像宣传海报、持续 glitch、高密度贴纸感、全页面高饱和撞色。

## 3. 夜晚 UI
可以强化：深色底、青 / 品红、发光边、数据标签、更明显斜切、快速转场。

## 4. 战斗 UI
允许：强对比、大色块、高速动效、技能数据轨迹、波形 / 节点、更明显角色色彩身份。

## 5. 异常 UI
视觉强度最高：glitch、信息错位、数据流、文字篡改、UI 侵入场景、高饱和青 / 品红 / 紫。
但必须保持核心信息可读。

## 6. 角色显示
探索 / 战斗：4 头身。
对话 / 人物资料：7 头身立绘。

## 7. 核心原则
> **功能页耐看，高潮页出拳。**
