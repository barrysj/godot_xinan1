# UI 视觉与实现规范 v0.3

## 1. 核心定位

> **校园数字系统 + 图形化设计 + 分层赛博强度**

原则：

> **功能页耐看，高潮页出拳。**

---

## 2. 日常 UI

关键词：
- 白 / 浅灰
- 青蓝主强调
- 留白
- 清晰
- 稳定
- 轻数字感

允许：
- 少量斜切
- 少量节点
- 少量电路线
- 简洁标签
- 轻动画

品红与黄：
- 只做重点交互与提示

禁止：
- 每屏都像宣传海报
- 持续 glitch
- 高密度贴纸感
- 全页面高饱和撞色

---

## 3. 夜晚 UI

允许：
- 深色底
- 青 / 品红
- 发光边
- 更强标签
- 数据层叠
- 更明显斜切
- 更快速转场

---

## 4. 战斗 UI

允许：
- 强对比
- 大色块
- 技能数据轨迹
- 波形
- 网络节点
- 角色色彩身份强化
- 快速动画

---

## 5. 异常 UI

视觉强度最高：
- glitch
- 信息错位
- 数据流
- 文字篡改
- UI 侵入场景
- 高饱和青 / 品红 / 紫
- 故障提示
- 节点失控

前提：
> 核心操作必须可读。

---

## 6. 角色显示

探索 / 战斗：
- 4 头身

对话 / 人物资料：
- 7 头身

不要缩放到破坏比例感。

---

## 7. 核心页面

### 首页
包含：
- 主视觉
- 今日事项
- 校园动态
- 主导航
- 剧情 / 学习 / 探索 / 社团入口

### 课程表
要求：
- 真正可读
- 时间轴清晰
- 当前课程清楚
- 本周重点明确

### 任务板
可参考：
- To-do
- Kanban
- Sprint

但文案与状态要校园化。

### 关系网
推荐：
- 人物头像 = 节点
- 普通关系 = 青
- 亲密 / 情绪 = 品红
- 可行动事件 = 黄

### 校园地图
- 俯视或轻等距
- 建筑清楚
- 路径清楚
- 图标统一

### 对话
- 7 头身立绘
- 选项明确
- 重大分支可强化色块与动画

---

## 8. 组件规则

### 标题
- 粗体
- 几何感
- 一级层级可更张扬

### 按钮
- Normal / Hover / Selected / Disabled 清楚
- 高亮优先黄或品红

### 卡片
- 白底 / 深底
- 圆角克制
- 可用锐角 / 斜切品牌形状

### 图标
- 简洁
- 图形化
- 少量像素语言
- 避免复杂拟物

---

## 9. 响应式

至少验证：
- 1920×1080
- 2560×1440
- 16:10

要求：
- 优先 Container / Anchor
- 核心信息不依赖固定像素坐标
- 图片裁切策略记录在 Manifest

---

## 10. 动效

普通反馈：
- 120～220ms

推荐：
- slide
- wipe
- diagonal reveal
- tag pop
- node connect

避免：
- continuous shake
- constant glitch
- blocking animation
