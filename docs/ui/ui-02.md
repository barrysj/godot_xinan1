## 当前能力

对象统一采用图标→悬停摘要→点击详情；装备槽、背包和图鉴同源。详情支持空白／Esc关闭，装备操作显式显示归属与结果；战中只读。

人物状态显示生命／护盾合条、唯一行动条、个人产码节点和意图泡泡。产码收拢、飞码与伤害数字读取真实模拟事件，暂停冻结，简化特效保留数值。代码、破解与道具集中于底部操作区，意图和释放信息各自排布；人物统一按脚底排序。悬停或固定详情的操作暂停与手动暂停分开。

奖励、热点、对象和终端回收复用选择子页。标题、故事、行动、后果和保存状态分层；常见三候选同屏，长内容滚动。结果图标／文字／颜色共同表达。事件返回遵守当前节点权限，置灰说明不进入按钮文案。

校园导览采用两步操作：先点击地图上的区域标签／区域面，再展开该区域路线的全部圆形地点节点，包括分支、已走过和后续地点。点击／Enter切换地点边框并显示详情，悬停和键盘焦点只提供轮廓反馈，不替换点击选定的信息。地图页“开始探索”仍进入原开局策略并从第一站出发；下一站页所有地点可查看，但只有当前站次的候选可“前往”，浏览其他地点会禁用前往并显示原因。会堂商业街拆为成电会堂和商业街两个地理节点，分别显示名称，共用原终末站点与进入动作，不增加战斗站次。基础实验大楼按负责人提供的编辑器坐标(925,740)落点。

右下角详情卡复用正式地点图片，保留当前位置／站次、探索起点、终端状态和确认；三态外观在右上切换，缩放在左下。恢复后的地图与图片为日间。方向键／Tab可操作节点和动作，区域展开及返回时交接键盘焦点。圆圈随地图移动，靠近屏幕边缘／详情卡时通过引线保留真实锚点；密集节点把上方名称放到圆圈上方，透明边距不拦截邻居点击。已走过用勾号，非当前节点图片减弱；选中暖黄双环与独立键盘焦点标记保留。离开页面移除旧控件。
