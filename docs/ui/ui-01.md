## 独立暂停与四档播放速度（2026-10-08，已汇总（2026-10-10））

基线为本轮已合入的原主线战斗与HUD，未改战斗规则。战斗暂停按钮只暂停/恢复，不再打开菜单；P同样控制战斗暂停，Esc/右上菜单保留原菜单。菜单记录打开前的手动暂停状态，关闭菜单、取消退出再关闭均恢复该状态；从运行中打开菜单后关闭则继续运行。手动暂停期间仍可操作暂停按钮、菜单和速度。重新编队或回基地时清除战斗手动暂停，菜单退出/保存功能保留。

播放速度使用float，循环0.5、1、1.5、2倍；固定步长模拟和动作表现沿用同一倍速，时钟及速度按钮正确显示小数，不再取整。旧短局检查点读取保留四档速度；M1战役仍沿用其原有检查点范围，本改动未增加存档字段。原战场动态底板收窄至x36..380，信息按字体实际宽300px截断，给中央技能卡留出空间；旧父画布飘数删除，由统一状态层的命中反馈接管，火花效果保留。

验证入口：`Godot --path . --rendering-method gl_compatibility --log-file .godot/playback-verified.log scenes/battle_demo/playback_controls_check.tscn -- --capture`，51 checks / 0 failures。覆盖原Campaign真实鼠标按钮、P/Esc、取消退出、关闭菜单保留手动暂停、四档循环、0.5倍推进半秒模拟、旧短局四档检查点往返、重新编队及回基地清理。1920×1080 / 2560×1440 / 1920×1200六张实机截图 `.godot/playback-paused-*.png`、`playback-half-speed-*.png`；隔离存档，未写用户原存档。手柄实体设备未验证。

## 全局基准速度（2026-10-16，待统筹）

唯一参数 `game/visual/game_tempo.gd::BASE_SCALE = 0.8` 由 `project.godot` 的 GameTempo 自动加载项写入 `Engine.time_scale`。这是相对原版本的全局时间倍率；调节基础节奏只修改此常量。游戏 delta、角色动画、UI Tween、派遣演出与游戏时间定时器一起减速，界面不得再重复乘 0.8。战斗 `speed` 在此基础上相乘：显示 0.5× / 1× / 1.5× / 2× 分别对应原版本 0.4 / 0.8 / 1.2 / 1.6 倍。调试加速松开后恢复 BASE_SCALE。暂停仍由原手动暂停／菜单状态负责。

系统时间戳、文件保存时间和明确忽略 time_scale 的真实时间测量不变；局内用时属于游戏时间。本参数不改变音频采样播放速率。

验证基线：`3fdb526` 加本次修改。Godot 4.7.2 标准版，`--headless --path . res://tools/tempo_check.tscn` 测得 delta / 真实时间 = 0.8000，UI Tween / 真实时间 = 0.8000，0失败；`--path . --rendering-method gl_compatibility res://scenes/battle_demo/playback_controls_check.tscn -- --capture` 51项／0失败，三种尺寸实机截图 `.godot/playback-*.png`。Web 正式包已走通序章战斗、派遣与路线出发，UI 与角色演出正常；发布验收见 RELEASE-01（2026-10-16）。待统筹影响：全局节奏降低20%，未改战斗数值与存档格式；真人节奏仍待体验。
