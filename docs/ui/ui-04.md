# UI-04 · 项目设置、声音与显示

- 功能 ID：UI-04
- 当前状态：已实装；2026-10-16，基线 `21b23b83`。

## 玩家能力与接入范围

主菜单设置使用项目界面与打包思源黑体。提供操作指引、简化特效、总音量／音效／音乐；桌面端提供全屏、垂直同步与帧率上限，Web 隐藏这些由浏览器管理的选项。只展示当前支持的简体中文，不保留模板语言及无关设置。

操作速查说明地图、阵型、暂停与速度操作，常用术语复用彩色悬停／点击解释。设置正文可滚动，保存、取消和恢复默认固定在面板底部。

## 实现与规则入口

- [设置页](../../scenes/menu/settings_menu.gd) 接入原 [主菜单](../../scenes/menu/menu.tscn)。
- 继续使用 [GGT_GameConfig](../../addons/ggt-core/autoload/game_settings_config.gd) 的同一 `settings.cfg`，不创建第二套玩家设置系统。
- 调整即时预览；保存持久化，取消（含 Esc）恢复打开时快照，恢复默认也须保存。保存失败留在界面并提示。
- 操作指引开关由原教学读取，不重置探索进度；简化特效接入原代码 HUD，战斗内开关同步保存该偏好。
- 音量使用既有音频总线；不代表所有场景已配音乐和音效。简化特效当前针对破解粒子与代码飞行，不改变战斗规则或全局基准速度。
