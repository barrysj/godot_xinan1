# 战前卡片部署 Task Spec

依据：2026-09-12 用户在当前会话直接指定的交互需求。本任务仅实现该交互，不重新定义美术方向。

- 入口：战斗 Demo、正式冒险的新战斗；我方初始无部署，保留现有六个可部署格和四人出战规模。
- 底部用人物卡片替代战前日志；复用现有角色 portrait、主 Theme、comic_ui 卡片形状，不新增或替换正式美术资产。Manifest 中的 concept 示例不使用。
- 卡片 hover 轻微放大/抬升；点击后保持抬起。候选格显示 35% 不透明度的现有角色图像。
- 点击卡片、点击有效格进入预览；预览上方只显示绿色对勾、红色叉号。点击其他空格切换候选位置。确认才修改部署；取消保留原部署。
- 按住卡片移动超过 8 个逻辑像素判定为拖动。有效格内显示预览，松手立即部署；场外/敌方/占用格松手不修改部署，无确认按钮。
- 已部署卡片保留并标注状态，可换位或撤回。最多四人，满四人才可开战；提示置于状态文本，不塞入按钮。
- 新遭遇清空我方部署；该场暂停、重试、存档恢复保留已确认位置。未确认的选择/拖放为临时状态。
- Anchor 根节点、HBoxContainer 卡片行沿用 1280×720 逻辑画布缩放；hover 动效读取 animation Token 的 micro 时长。
- Esc 优先取消部署手势，失焦/暂停取消手势，防止恢复后误部署。图标按钮有确认/取消工具提示与键盘焦点。
- 验收：点击与拖动、换候选格、取消不落子、无效松手、占位与人数上限、部分阵容存档、开战、暂停、正式冒险；运行并截图验证 1920×1080、2560×1440、1920×1200。
